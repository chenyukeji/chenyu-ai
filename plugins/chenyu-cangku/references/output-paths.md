# 输出目录规范

除非用户明确指定其他保存位置，仓库插件生成的业务文件统一写入当前工作空间中的 `chenyu-ai` 仓库：

```text
<chenyu-ai>/outputs/chenyu-cangku/<交付部分>/<YYYY-MM-DD_任务简称>/
```

先定位包含 `plugins/chenyu-cangku` 的仓库根目录；无法唯一定位时先确认路径。不得把真实业务输入或生成结果写入插件源码、安装缓存或分发 ZIP。

## 交付部分

| 目录 | 内容 |
| --- | --- |
| `lingxing-product-import` | 领星产品录用 Excel 与按 MSKU 配对 Excel |

任务简称优先取输入文件名的稳定短名，例如 `2026-10-08_jiuyue-xinpin-bulu`。同名目录已存在且本次是新运行时依次追加 `_02`、`_03`；只有用户明确要求继续原任务时才复用原目录。两份输出必须放在同一个任务目录，不能覆盖原始输入。

用户明确指定的输出目录优先于本规范。
