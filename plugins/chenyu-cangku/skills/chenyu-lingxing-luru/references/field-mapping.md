# 字段映射与校验规则

## 输入清洗

- 只处理至少一个单元格有值的业务行；纯格式空行忽略。
- `Msku` 去除首尾空格、换行及尾部 `|`/`｜`，清洗后必须唯一且非空。
- 输入中的小写 `sku` 当前不写入两份输出。已确认样表要求产品录用 `*SKU`、配对 `*SKU` 和配对 `*MSKU` 都使用清洗后的 `Msku`。
- 必填：日期、账号、运营、开发、产品、产品名称、Msku。
- 成本和重量允许为空；非空时必须是非负数字。
- 尺寸允许为空；非空时必须可拆为三个正数，分隔符支持 `*`、`×`、`x`、`X`。

## 领星产品录用表

基于 `Product-V392.xlsx`，保留原示例行，新增数据从示例行之后开始。按表头名称写入，不按固定列号猜测。

| 输入列/规则 | 产品模板字段 | 输出规则 |
| --- | --- | --- |
| `Msku` | `*SKU` | 使用清洗后的 Msku |
| `产品名称` | `品名` | 原值 |
| 固定值 | `产品类型` | `普通产品` |
| `状态` | `状态` | 输入非空时沿用；空白时默认 `在售` |
| 固定值 | `单位` | `件` |
| `开发` | `开发人` | 原值 |
| `日期` | `开发日期` | 规范为 `YYYY-MM-DD`；旧模板没有该列时兼容留空 |
| `运营` | `产品负责人` | 原值 |
| `产品` | `SPU` | 原值 |
| `进货成本` | `采购成本(CNY)` | 数值，空值保持空 |
| `采购价` | `采购备注` | 非空时写 `原始采购价：0.00 CNY` |
| `单个重量(净重）` | `单品净重` | 数值；非空时单位列写 `g` |
| `毛重（取最大者）` | `单品毛重` | 数值；非空时单位列写 `g` |
| `尺寸` | `包装规格长/宽/高` | 按长、宽、高拆分；非空时单位列写 `cm` |
| 尺寸计算 | `全部国家头程费用(含税)` | `max(2, 长×宽×高×0.006)`，四舍五入到 2 位 |
| 固定币种 | `全部国家头程费用币种` | 头程费用非空时写 `CNY` |

如果成本、重量或尺寸为空，仍生成该产品行，只把对应字段和单位保持为空。

## 按 MSKU 配对表

| `店铺名称` | 按账号映射 |
| `国家` | 对应店铺国家 |
| `是否同步listing图` | 固定 `是` |

已确认账号映射：

| 输入账号 | 店铺名称 | 国家 |
| --- | --- | --- |
