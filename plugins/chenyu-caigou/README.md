# 晨玙 Amazon 采购插件

面向采购和供应链岗位的分析插件，用于比较供应商条件、制定采购或补货计划，并整理交期、质量、物流和库存风险。

## 包含能力

- 供应商报价和条件标准化
- MOQ、交期、质量、付款及物流比较
- 销售预测和库存驱动的采购建议
- 交期跟踪、异常整理和供应风险预警

## 常见输入

- 产品需求和目标规格
- 供应商报价单及沟通记录
- MOQ、交期、付款、物流和质检资料
- 销售预测、库存、在途和安全库存数据

## 交付与边界

插件输出可审核的比较、采购计划和风险建议。它不会代替员工联系供应商、承诺订单、签约、下单或付款；缺失和冲突信息会作为待确认项保留。
