# 输出目录规范

除非用户明确指定其他保存位置，所有采购任务文件统一写入当前工作空间中的 `chenyu-ai` 仓库：

```text
<chenyu-ai>/outputs/chenyu-caigou/<交付部分>/<YYYY-MM-DD_产品简称>/
```

先定位包含 `plugins/chenyu-caigou` 的 `chenyu-ai` 仓库根目录；若当前目录不是仓库，可检查当前工作空间下唯一的 `chenyu-ai` 子目录。无法唯一定位时先确认路径，不得写入插件源码目录、安装缓存或用户上传文件所在目录。

## 交付部分

| 目录 | 内容 |
| --- | --- |
| `supplier-comparison` | 供应商比较表、报价口径和推荐依据 |
| `procurement-plan` | 采购数量、预算、下单窗口和到货计划 |
| `supply-tracking` | 供应链节点、偏差、异常和风险跟踪报告 |
| `combined-delivery` | 确实把多个采购部分合并在同一个最终文件时使用；不重复复制各部分已有文件 |

任务文件夹使用执行当天的本地日期和简短产品名，例如 `2026-09-20_tree-skirt-120cm`。清理 Windows 不允许的路径字符，产品名无法确定时使用稳定的任务简称。一次综合任务在不同交付部分下复用同一个文件夹名，便于相互对应。

同名文件夹已经存在且本次是新运行时，依次使用 `_02`、`_03`；只有用户明确要求继续原任务时才复用原目录。先确定真实要保存的成果再创建目录，只查看、解释或诊断时不创建空目录。原始输入不覆盖，最终成果和必要中间计算保存在所属任务目录。

用户明确指定的输出目录优先于本规范。
