# 晨玙 Amazon 物流插件

`chenyu-wuliu` 独立负责物流岗位的箱唛发货发票；运营的 Amazon 买家订单商业发票仍属于 `chenyu-yunying`。

## 已有能力

- `chenyu-xiangmai-fapiao`：根据箱唛照片与已核实的领星商品资料，生成联航或驿路达原格式 `.xls` 发货发票。
- 输入包含承运商、FBA 箱号、渠道、收件仓地址编码与已确认的申报字段。缺失事实需先补齐。
- 保留原有模板、地址公式、下拉规则及格式，不从历史发票猜测新货件数据。

## 执行条件

生成脚本使用 Windows 上的 WPS 表格。当前网站尚未接入该执行环境，只开放物流任务表单和材料选择，正式提交生成在环境接入后开放。不要用格式转换替代原脚本。

默认输出：`outputs/chenyu-wuliu/shipping-invoice/<YYYY-MM-DD_任务简称>/`。不修改领星数据，也不向承运商提交发票。
