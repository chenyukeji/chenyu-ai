# 输出目录规范

除非用户明确指定其他保存位置，所有发货文档统一写入当前工作空间中的 `chenyu-ai` 仓库：

```text
<chenyu-ai>/outputs/chenyu-fahuo/<交付部分>/<YYYY-MM-DD_任务简称>/
```

先定位包含 `plugins/chenyu-fahuo` 的 `chenyu-ai` 仓库根目录；若无法唯一定位，先确认路径。不得把真实订单成果写入插件源码、安装缓存、分发 ZIP 或用户上传文件所在目录。

## 交付部分

| 目录 | 内容 |
| --- | --- |
| `commercial-invoice` | 由固定母版生成的商业发票 PDF，以及必要的核验记录 |

商业发票任务的任务简称使用完整 Amazon 订单编号，例如 `2026-10-08_403-1234567-7654321`。同名文件夹已经存在且本次是新运行时，依次使用 `_02`、`_03`；只有用户明确要求继续原任务时才复用原目录。先确定真实要保存的成果再创建目录，只查看、解释或诊断时不创建空目录。

用户明确指定的输出目录优先于本规范。无论目录如何指定，商业发票 PDF 文件名仍必须严格为 `<订单编号>.pdf`。
