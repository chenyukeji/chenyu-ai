# 晨玙 Amazon Listing 规则

更新日期：2026-09-26

本文件是 `chenyu-yunying` 插件生成欧洲站非媒体类目 Listing 的统一规则。平台硬性规则与晨玙内部写作标准分开标明；目标站点或类目存在更严格且已核实的要求时，从严执行。

## 1. Amazon 平台规则

- 非媒体类目 `Item Name` 最多 75 个字符，包含空格。
- `Item Highlights` 最多 125 个字符，包含空格。
- 两个字段都参与搜索，Amazon 不对其中一个设置搜索优先级。
- 最重要的变体属性保留在 Item Name，受 75 字符限制无法容纳的其他属性移入 Item Highlights。
- 标题不得使用 Amazon 禁止的特殊字符；同一实义词不得无意义反复出现，介词、冠词和连词等语法词除外。

官方依据：

- [Amazon 2026 年 Item Name 与 Item Highlights 说明](https://sellercentral.amazon.de/seller-forums/discussions/t/c6f803a9-67a5-4c02-809a-bf3a9cb6b25f?postId=c6f803a9-67a5-4c02-809a-bf3a9cb6b25f)
- [Amazon 产品标题规范公告](https://sellercentral.amazon.de/seller-forums/discussions/t/0cbed52b-f184-452d-909e-6f8501a28791)

## 2. 产品事实与同款证据

事实优先级：

```text
用户当前明确说明 > 自有开发资料 > 已确认自有图片 > 第一条同款链接 > 其他同款链接 > 普通同类竞品
```

用户、采购记录或产品证据确认第一条链接与自有产品是同款时，可以采用该链接中与当前规格不冲突的功能、结构、材质表现、安装、使用、清洁、收纳、覆盖效果和适用场景。事实记录必须同时保存“同款确认”和具体 ASIN/字段来源。

不得迁移竞品品牌、店铺身份、ASIN 文案、不同尺寸、不同数量、不同配件、竞品独有版本、认证、质保和售后承诺。开发资料与同款链接冲突时，以开发资料为准。未确认同款时，竞品只用于关键词和表达研究。

## 3. Item Name

- 单行，最多 75 个字符；内部目标为 70–75 个字符。
- 少于 68 个字符视为信息不足；68–69 个字符提示继续优化。
- 只能用真实、高相关关键词和关键差异补足长度，不用低价值词或空泛形容词凑字数。
- 不用 `/` 分隔关键词或场景，按目标语言自然成句。
- 使用 2–4 个不同的核心关键词；词短时可增加核心词，不能用颜色、数量或普通形容词占据核心词名额。
- 数量为 1 时不写数量；数量大于 1 时，本地化数量短语紧贴在第一个核心产品词前。
- 能解释价格、适配或购买差异的重要规格优先放在标题前部，例如层数、加厚、双面、带灯、可折叠。普通尺寸、颜色和内部款号移入 Item Highlights。
- 主要场景不是标题必填项。有高搜索价值且有空间时放一个主要场景；多个场景放入 Item Highlights。
- `Design A/B/C`、`Diseño A`、`Variante A` 等内部编号不得进入任何买家可见字段。只有用户明确确认它本身就是买家识别的公开变体名时，才可记录到 `buyer_visible_variant_terms` 后保留。
- 父体只写共用事实；子体只写当前 SKU 的真实属性。

推荐结构：

```text
[确认品牌] + [数量>1] + 第一核心产品词/关键差异 + 其他核心词 + 高价值属性或场景
```

## 4. Item Highlights

- 每个站点、每个子体必填，单行，最多 125 个字符。
- 内部目标为 115–125 个字符；不足时继续检查有无真实规格、结构、场景和高相关关键词可补充。
- 用一句自然、可读的当地语言表达，不写成逗号堆砌的关键词清单。
- 优先放标题未容纳的核心/长尾词、重要尺寸、材质结构、其他变体信息、安装适配和多个使用场景。
- 可以自然重复标题中的关键差异和核心关键词，但必须补充新的规格、结构或场景信息。

## 5. 五点卖点

- 必须正好五条。
- 每条格式：`相关 Emoji＋【本地语言利益点标题】＋2–4 句正文`。
- 只计算正文时，每条必须超过 200 个可见字符；200 个及以下不合格。
- 不设置机械最高字符数，但不得用同义改写、空话或重复句凑长度。
- 每条围绕一个具体产品特点展开，用数量、部位、尺寸、材料表现、操作或真实用途补足信息。特点本身已清楚时，不强制追加“因此更方便”一类利益解释。
- 第一条直接说明最重要的产品差异和购买理由，不以背景介绍或免责声明起笔。

### 5.1 买家文案硬规则

- 所有句子都直接回答买家关心的问题：产品包含什么、有什么结构或细节、怎样使用、适合放在哪里，以及使用后能得到什么具体结果。
- 不写面向卖家、审核人员或运营流程的解释，例如“便于买家区分实际包装与场景道具”“让买家清楚了解包装内容”“保持整套产品的统一识别度”“与标题/图片一致”。这类句子没有提供新的产品信息，视为空话。
- 不使用“买家、顾客、消费者”作为文案叙述对象来解释信息呈现方式；直接描述产品事实和使用结果。
- 同一条五点内不得出现逐字重复或仅替换少量词的同义句；五条之间也不得用相同句子重复凑长度。每个句子必须增加新的事实、动作、条件、位置或可观察结果。
- 超过 200 字符是最低完整度要求，不是填充目标。内容不足时，应补充已证实的尺寸边界、结构细节、实际操作、适配位置、用途、收纳或使用条件，不得补充运营说明、抽象氛围词、作图指导或免责声明。
- 可以在不同前台字段重复核心事实，但必须按字段深度展开；不允许在同一个字段内机械复述。
- 不把数量的算术结果或功能的否定重述当作新增信息。例如“4个可分成4份”“一次准备四份小礼物”“无需另外挑选”“不受固定姿势限制”“换位置后仍可重新塑形”“单独使用仍保留完整造型”均不是独立卖点，不能用来补长度。真实的套装构成、可调部位和用途可以直接写一次。
- 逐句做删除检查：删除该句后，买家是否少知道了某项具体属性、操作条件或用途？若没有，就删除；不能仅因为多了一个场景名或换了一个动作词而保留。

### 5.2 Listing 与作图要求隔离

- Listing 可以说明产品适合放在哪里、如何调整或如何使用，但场景必须服务于购买判断或实际使用，不能转写为美工构图方案。
- “画面更丰富、增加层次、前后错落、不同高度排布、形成视觉焦点、增强动态感、避免呆板、近景/远景、构图、镜头、留白、主体占比”等均属于作图要求，不得进入 Item Highlights、五点或详情。
- 对可弯折、可调节产品，直接写可调部位和有证据的姿态；只有特殊锁定、调节范围或操作条件确有证据时才展开。不要把“可以调整”再解释成“不受固定姿势限制、换位置仍能调整”，也不能写画面动态感或构图效果。
- 竞品图片只能用于确认可见结构、尺寸关系和真实使用位置；竞品的拍摄角度、道具搭配、前后景、摆放层次和构图方式不得迁移为 Listing 卖点。
- 中文翻译也执行同一边界，不得因为它不属于上传字段而保留作图口吻。

推荐分工：

1. 准确包装/变体组成、核心差异，以及该组合的具体使用方式。
2. 关键结构或功能、实际操作动作，以及功能带来的可观察结果。
3. 材质或可见设计细节，以及这些细节在触摸、安装、佩戴或实际使用中的具体表现。
4. 重要尺寸、适配边界和明确的摆放/安装位置。
5. 礼赠、使用场景、清洁收纳或另一项未覆盖的购买理由；必须提供新的具体信息，不得总结前四点。

第一条同款链接是开发资料未展开内容的主要补充来源。不能只写“营造氛围、精美设计、用途广泛”等空话，必须说明产品具体有什么、如何使用以及带来什么结果。

## 6. HTML 详情描述

只使用 `<p>`、`<br>`、`<b>`，按以下顺序生成：

1. 产品概述：2–3 句，说明产品是什么、核心结构、主要用途和场景。
2. 3–5 项编号功能：每项 2–4 句，详细说明特点、材料/结构、使用方式、解决的问题、买家结果和必要边界。
3. 产品参数：写清测量部位、数值和单位。
4. 使用或保养方法：有可靠事实时填写，位于参数之后、包装之前。
5. 包装内容：逐项列真实数量；场景道具不算配件。
6. 必要注意事项：仅在确有事实时填写，位于包装内容之后。

包装内容默认只写实际包含的物品和数量，不自动追加“图片中的其他装饰/道具不包含”等笼统免责声明。只有某个具体配件极易被误认为随货提供，且自有资料、用户说明或已确认同款证据明确要求提示时，才在“注意事项”中点名该具体配件；不得把免责声明写进包装内容来凑字数。

## 7. 前台字段重复

取消“标题、Item Highlights、五点和详情不能重复”的硬性要求。

允许关键差异同时出现在标题、Item Highlights 和五点 1；重要尺寸同时出现在 Item Highlights、五点和详情；核心关键词在多个前台字段自然出现；主要场景在 Item Highlights、五点 4 和详情中重复。不同字段只需承担不同深度：标题负责识别，Item Highlights 负责补足，五点负责解释，详情负责完整展开。

逐字复制大段文案只作为质量复核提示，不因关键词、尺寸或核心事实重复而判定失败。

## 8. Search Terms

Search Terms 最后生成，只填写 Item Name、Item Highlights、五点、详情和其他前台属性尚未覆盖的增量词。

### 8.1 候选词来源

1. 从第一条同款链接提取 ASIN，并作为主要参考 ASIN。
2. 使用卖家精灵反查该 ASIN 的自然关键词。
3. 同时从全部有效参考链接的标题提取产品词、同义词、当地常用词形和高相关长尾词；不得只依赖卖家精灵，也不得只看第一条链接标题。
4. 前台去重后若有效候选仍少，继续查目标站点其他同类商品的标题，不限于开发文档已有链接。只吸收与自有产品类型、结构和用途匹配的真实同义词及词形；不同结构的窗板、单独售卖的软管、其他设备等不得借词引流。来源记录使用 `same_category_title_terms`，保存商品 ASIN、标题和站点。
5. 三类候选分别保留来源 ASIN、来源字段和来源站点；候选短语应经过目标 Amazon 站点前 20 个自然结果复核，未完成复核时须明确标为待验证，不能声称搜索量或相关性等级已核实。
6. 优先采用目标站点数据；只有美国站数据时，只作为语义候选，不声称具有欧洲当地搜索量。
7. 删除品牌、ASIN、竞品身份、无关节日词、错误规格和与产品不符的功能词。

### 8.2 Amazon 搜索相关性复核

把候选短语逐个放到对应 Amazon 站点搜索，检查前 20 个自然商品，广告位不计：

- 同款或直接同类占比不低于 70%：高相关，优先采用。
- 占比 40%–69%：中等相关，有剩余字节时采用。
- 占比低于 40%：过泛或有歧义，通常删除。
- 结果主要是其他品类、配件或不同用途商品：删除。

不以 Amazon 显示的结果总数量判断相关性，以首页靠前自然结果的产品构成为准。研究记录保存候选短语、来源 ASIN、卖家精灵来源站点、Amazon 验证站点、检查数量、同类数量、相关性等级和采用决定。

### 8.3 最终填写

- 审核时保留完整关键词短语；写入后台时再按词元去重，只保留前台未出现的增量词。
- 全部小写、单行、单空格、无标点。
- 不重复词，不机械并列同一词的单复数和词序变体，不写停用词。
- 不写品牌、ASIN、主观宣传词、临时性表达和无关流量词。
- 控制在 249 个 UTF-8 字节以内。高相关增量词不足时允许留短，不用泛词填满。
- 所有已经通过审核、且前台尚未覆盖的有效增量词都应写入；不得因为只取少量候选而让 Search Terms 无故过短。
- 发现某站 Search Terms 明显偏短时，先核对全部参考链接和其他匹配的同类标题是否遗漏可用词，再决定留短；不设必须填满 249 字节的长度目标，也不以泛词凑长度。

## 9. 变体与交付

- 每个子体分别生成 Item Name、Item Highlights、五点、HTML 详情和 Search Terms。
- 能明显影响购买和价格的重要变体差异进入标题前部；普通变体属性放入 Item Highlights。
- 只有确认父子关系及合法变体主题时才生成父体标题。
- Excel 每个站点按“子体标题、Item Highlights、五点 1–5、HTML 详情、Search Terms”的顺序排列。
- 每个目标站点文案旁增加完整“中文翻译”列，再保留简短参考来源；中文翻译供中国卖家核对，不属于上传字段，不计入目标站点字符或字节限制。
- 中文翻译必须与目标站点原文逐字段对应，保留数量、尺寸、使用条件、卖点顺序和 HTML 信息块，不得新增原文没有的承诺；Search Terms 中文列只解释词义。
- 产品内容统一使用“产品名称、产品图片、产品尺寸、产品材料、产品规格、补充信息”六列，与作图交付保持同一风格。
- 产品事实、同款证据和买家可见文案分开保存。
- `Design A/B/C` 等内部列名可留在运营表头或内部参考列，但不得进入 Item Name、Item Highlights、五点、HTML 详情或 Search Terms。

## 10. 交付前检查

- Item Name 为 68–75 字符，目标 70–75；Item Highlights 不超过 125 字符并尽量达到 115–125。
- 标题使用 2–4 个真实核心词，数量和重要差异位置正确。
- 五点正好五条，每条正文超过 200 个可见字符并包含 2–4 句。
- 五点与详情全部使用买家可读的产品语言，不含运营解释、信息呈现说明、作图构图语言或笼统道具免责声明；同一字段内无重复句和同义复述。
- 详情包含 2–3 句概述、3–5 项详细编号功能、参数和包装，其他块按事实填写。
- 允许前台字段自然重复，不执行机械去重。
- Search Terms 从卖家精灵、全部有效参考标题和必要时补查的同类商品标题建立候选池；只含匹配本品、前台未覆盖的增量词，不超过 249 UTF-8 字节。来源或自然位复核未取得时明确披露，不伪称已验证。
- 所有数字、材质、功能、包装和变体均可追溯到自有证据或“同款确认＋具体竞品点位”。
- 母版中的示例文案不是事实来源，也不是已审核文案。导入母版只复用结构和样式；即使同产品再次生成，也必须按本次用户反馈逐句复核目标语言与中文翻译。格式、字符数和脚本通过不代表语义质量通过。
