# PDF 原母版 1:1 版式规范

这不是“参考样式重新画一张发票”。`assets/blank-reference-template.pdf` 是用户提供的原始 WPS 商业发票经过**清理旧订单数据**得到的可复用 PDF 母版。母版保留原始 WPS 输出中的公司抬头、字体、灰色横条、右侧联系方式、买卖方字段标签、灰色七列表头、七列格线、两条底部边线和固定文案。已清理旧买家、旧订单号、旧商品、旧金额、旧税额、旧城市和旧邮编；**不提供旧买家发票原件**。

## 版式必须原样保留

- 纸张：A4，595.3 × 841.9 pt，页边距和上下留白均使用 PDF 母版原位置。
- 抬头：按 [卖家母版](seller-templates.md) 居中打印完整公司名称。原母版为 `shenzhenshijiuyuekejiyouxiangongsi`；Renhaoyuan 母版为 `shenzhenshirenhaoyuanmaoyiyouxiangongsi`，不能只写店铺简称。各母版左侧地址、电话与 `COMMERCIAL INVOICE` 保持已确认版式。
- 左栏：`Importer/Buyer/Receiver:` **优先填写同订单买家明确开票留言的公司/个人抬头，无留言才用配送地址首行**；不改用联系买家显示名。`Contact:` 和 `Company Name:` 标签保留，值留空；如提供买方税号，在该空白区域单独标注 `Buyer VAT/NIP:`，不占用卖方税号栏。`Address:` 仅填写对应开票街道与楼栋，不重复姓名；其余字段保持原位置。
- 右栏：`Manufacturer/Seller/Shipper:`、`Sales:`、卖家地址、`VAT number:`、`Date:` 使用原位置。Renhaoyuan 的 Sales 为 `Renhaoyuan`，附已确认邮箱；地址用拼音，不含 Business registration。卖家身份、地址及电话与所选母版一致，不默默套用另一卖家。
- **Shipping way 固定为 `Paypal package`**，本值已经印在原母版上，不因 Amazon FBA / 加急改变。
- **表格的列宽、边框、灰色表头、留白都从原母版读取，不重新绘制。** `Item No.` 使用 Amazon 订单号分三行居中，**不是 SKU**；`Item Name` 用约 12pt Times 粗体居中自动换行，`Description` 用粗体居中短商品名且不得默认空白；单价、数量和行金额用 12pt 衬线字体居中。长标题必要时小幅缩小字号，不可截断和溢出。
- 页尾：保留 `Shipping fee:` 和底部边线，在右侧依次显示 `Total Amount:`、`Amount excl. VAT:`、`VAT (税率):`；保留左侧 `TRADIN` / `G TERM:` / `ORGIN:`。总额、未税、税额基线分别为 y=639.29 / 655.29 / 671.29 pt，标签右边界 x=492、金额右对齐 x=550。灰色表头不移动；两商品页增加第二行，页尾上述坐标统一加 109.7 pt。
- 原模板 `Total Amount` 默认使用订单右侧“商品总计 / Item total”作为本次开票金额，记录来源；用户明确额外要求优先。不另要实付确认、不取销售净收益，不能编造或重复计算运费。确实看不到总计、只知小计时才说明小计来源。
- VAT 按实际配送国家／地区取税率 `r`。含税来源用 `Price / (1 + r) * r`；已确认未税来源用 `Price * r`，含税总额为原未税总额加 VAT，均四舍五入两位。未税金额使用含税总额减已舍入税额，以保证两者相加严格等于总额。PT 大陆 23%：€10.99 → 未税 €8.93、VAT €2.06。
- **VAT 同行对齐**：新 VAT 标签、币种与金额均使用 y=671.29 pt；三行金额使用同一比例字体、同一字号，金额和标签基线差小于 0.2 pt。不得叠在原旧标签上。
- 未确认的买家税号、运费、原产国、Tracking 和 Remote area 保持空白。**不能复制旧发票中的 `CHINA` 或 `No` 作为新订单事实**。

## 页面和异常

- 支持 EUR 与 PLN，按订单原币种原数值生成。PLN 替换两处表头和三行金额币种，表格图形不变。EUR 使用 €。其他币种需匹配已确认母版，禁止只改币种标签。
- 自有卖家 `imported` 使用原空白 PDF 的图形布局，清除固定卖家的公司、地址、Sales、电话后填写已确认快照；顶部地址与右侧卖方地址均固定保留 `ADD:` 标签，随地址换行排版，不得因清除旧卖家地址而丢失任一处标签；已知邮箱填在卖方地址上方空白处，不保留任何旧卖家值。只删替文字，不增加遮盖表格的白色矩形。
- 两种商品必须同页：在原七列表格下复制一行，保留原列宽、行高和字号，页尾整体下移一个商品行高度（109.7 pt）。超过两行才按每页两行分页；每页均展示本订单总额、未税金额和 VAT，不能把重复的订单合计当成各页小计相加。单商品位置不变。
- 卖家主体与所选母版不符、国家名或地址无法在固定栏中排下、超长标题最小字号仍超出时，停止并说明需要匹配或扩展母版；不偷偷删字。
- 生成后渲染 A4 图像，逐项检查 PDF 原母版灰色表头及边线、收件人、地址、`Item No.`、`Item Name`、`Description`、单价、数量、合计与 VAT，所有新内容均可选择复制。

## 跨国订单与运费促销

- 原母版 `Country` 静态打印 France；Renhaoyuan 空白母版没有预填国家。按各母版情况只清除该值并打印本单英文国家，不可漏填或出现两国叠字。
- `shipping_fee` 与 `shipping_discount` 均记录原值；固定表格的 `Shipping fee` 单行展示净运费，金额 `shipping_fee - shipping_discount`，无运费时留空，不能把促销抵扣再当成额外收入。
- VAT 百分比按实际配送国家／地区确定；打印 Country 可按买家开票留言填写，不能以账单国家覆盖配送税率。销售站点独立保留为订单来源。

## 日期填写规范

`Date:` 为订单购买日期（`purchase_date`），统一写 `DD/MM/YYYY`；不能用 PDF 创建日期、Amazon 配送截至日期或模板中的旧日期。购买日期缺失时停止并请求真实订单日期，不猜测。
