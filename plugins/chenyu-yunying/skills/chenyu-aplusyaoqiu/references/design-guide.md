# A+ 通用设计要求

## 页面阅读顺序

先回答“是什么、适合什么用途”，再解释“为什么适合、怎样使用、有哪些选择”。以下是可组合的设计起点，不是 Amazon 强制模板或固定图数。简单产品可从 3–5 个有独立价值的静态模块开始；最终数量服从真实内容及账号模块限制。

| 信息任务 | 推荐画面 | 文案与取舍 |
| --- | --- | --- |
| 场景引入 | 横向使用场景，产品及作用位置清晰；小件可增加一个有主辅关系的产品近景 | 一个核心利益点或用途标题；不用泛泛口号挤占产品 |
| 特点证明 | 有依据的结构/材质近景，或主画面配少量关联细节；一处标注对应一个对象 | 解释可见特点的价值，不能仅因看见纹理就推定材料成分或耐久性 |
| 操作或安装 | 按真实次序的 2–4 步动作，保持同一产品、视角和配件关系 | 步骤数由实际操作决定；没有操作需求的装饰品可改为摆放或搭配，不凑流程 |
| 尺寸、适配或套装 | 明确测量部位、接口、放置关系或完整售卖清单 | 参数有来源；用图解决选购判断，避免把全套规格堆成小字表 |
| 用途展开或效果收束 | 2–4 个有区别的真实用途，或一幅完整效果图 | 分格只是可选表达；每格说明不同用途，不用换背景重复同一意思 |

功能配件常优先“结构—适配—操作”；节庆装饰常优先“整体效果—细节—摆放/搭配”；保冷、收纳等用品常优先“使用关系—操作—适用场景”。按本品事实调整，不能将示例类目的用途迁移给所有商品。

## 构图与风格

- 整页统一配色、光线、字体层级和标签样式，横幅与细节卡片之间可以有节奏变化。配色由产品、季节及环境决定，不固定蓝橙色、圆角框或节庆背景。
- 主体应让人看清售卖产品及它与手、容器、家具或环境的真实关系。人物负责演示操作或提供比例，不遮挡关键部位；道具不能被误认成包装内容。
- 场景中保持本品颜色、图案、形状、连接结构和售卖数量。展示 DIY 后效果时明确它是使用示例，不能把后加彩绘、文字或道具当作到货状态。
- 放大主体与环境中的小主体可共存，但写清“特写＋整体使用”的主辅关系，不能让夸大的产品合成比例被理解为实际尺寸。手持、佩戴、接触、水面和安装位置须符合结构及用途。
- 每模块围绕一个主题，可含多个相关信息点；细节窗只补充主画面看不到的内容。三卡片、四格和左右分区都是工具，不为填格重复画面。
- 大场景须帮助理解用途、搭配或效果。纯环境氛围若无新增判断价值，应合并或删去；场景好看不等于证明产品性能。
- 参考图只借鉴信息层级、构图及表现方法；生产素材使用本品实拍、获授权素材或另行原创。不得把竞品图片简单去标替换后交付为本品图。

## 文案与手机端

- 默认一个简短标题配必要标签或一句解释；字数由目标语言、槽位和可读性决定，不强行限制为英文 1–3 词。标题、标签和后台正文各有分工，不重复整段 Listing。
- 图内文字写出逐字定稿与位置；后台文字另列。不要同时在图片及后台叠加同一句话，也不要将运营中文说明或占位文案烘焙上图。alt text 客观描述画面，用于辅助理解，不堆关键词。
- 先让画面表达，再补文字；用高对比、简洁字体和稳定层级。避免大段全大写、花体、密集小字以及覆盖关键结构的色块。
- 在约 375–390 px 宽的手机预览中检查标题、关键参数和产品辨识。这是内部检查条件，不是 Amazon 上传尺寸。不可读时减少文字、重排卡片或将解释放入后台文本；不能只放大字体造成遮挡。
- 后台支持独立移动端图片时为其单独排版并注明槽位；不支持时按实际自适应方式设计。重要信息不要只放在可能被裁去的边缘，不假定所有模块都中心裁切或所有多列模块都自动堆叠。

## 规格与事实

先选模块，再确定每个素材槽位的宽高。不能把方形图直接拉伸成长图，也不能把所有 A+ 都定为 970×600 或 1464×600。保留高分辨率可编辑源稿，按确认的模块尺寸单独导出；RGB JPG/PNG 可作为工作格式，实际字节上限和格式以目标后台为准。

以下仅是官方公开模块资料的参考值（核对日期 2026-10-12），不是整页统一规格或对未来后台的保证：

| 官方模块/资料项 | 参考槽位 | 使用边界 |
| --- | --- | --- |
| Standard Image & Dark/Light Text Overlay | 970×300 | 图层文字与后台叠加文字分别规划 |
| Standard Single Left/Right Image | 300×300 | 图片旁的后台文本不烘焙进小图 |
| Standard Three Images & Text | 每槽 300×300，共三槽 | 一个模块含三张素材，不算三模块 |
| Standard Four Images & Text | 每槽 200×200，共四槽 | 不同于一张横图内部自行拼四格 |
| Premium 官方类型概览 | 概览列出 1464×600 | 不能套用于全部 Premium 模块或移动端槽位 |

参考 [Amazon 标准模块模板](https://m.media-amazon.com/images/G/35/sp-marketing-toolkit/Sellerfacingguides/BO/Standard_A_Module_Templates.pdf)、[A+ 类型概览](https://m.media-amazon.com/images/G/01/BX_Marketing/2023/AMZ_OnePager_PremiumA_09a-4-21-2023.pdf) 及 [Amazon A+ 官方入口](https://sell.amazon.com/tools/a-content)。资料年代及账号可用性不同，生成实际任务时应重新核对对应模块；从竞品下载到的图片尺寸只记录为观察值。

发布内容不加入价格、折扣、促销按钮、星级评价、站外联系方式或无依据的第一名、功效、认证、环保及安全承诺。对比模块仅在有已确认的自有产品组合和适用后台模块时使用。泳池、水处理等产品不能从清澈水面推导杀菌效果；保冷产品不能从冰霜场景推导保冷时长；灯饰不能从场景推导电源、防水或儿童使用适用性。平台规则须查询当前目标站点官方要求，不把竞品已展示的内容当合规证明。
