# 写作与审核

本文件是 [插件 Listing 规则](../../../LISTING_RULES.md) 的执行细则。平台限制与用户当前任务要求冲突时，以已核实的更严格限制为准；用户对内容深度、顺序和格式的明确要求优先于默认写法。

## 事实模式

只有开发资料或用户确认的自有品牌才能进入文案。产品事实可以来自：

1. 自有开发资料、图片或用户确认；
2. 用户、采购资料或产品证据已经确认的同款竞品，并同时记录同款确认和具体 ASIN/字段。

同款模式可采用功能、结构、材质表现、适用范围、安装、清洁、收纳和使用效果。不得采用竞品品牌、冲突规格/数量/配件、竞品独有结构、认证、质保和售后承诺。未确认同款时，竞品只提供关键词和表达思路。

## 关键词与字段分配

- Item Name：2–4 个核心词、关键差异和可选的一个主要场景。
- Item Highlights：标题放不下的核心/长尾词、规格、材质结构和多个场景。
- 五点：详细解释产品特点、使用方式、条件和买家结果，可自然重复核心词和关键事实。
- 详情：完整展开全部信息，不以机械避重为目标。
- Search Terms：最后生成，只补前台字段和其他属性尚未覆盖的增量词。

前台字段之间允许重复关键词、尺寸、场景和同一核心卖点。不要为了“每个字段必须完全不同”牺牲信息完整度，也不要把整段原文逐字复制到多个字段。

## Item Name

推荐结构：

```text
[确认品牌]＋[数量>1]＋第一核心产品词/关键差异＋其他核心词＋高价值属性或场景
```

- 68–75 个字符，目标 70–75；包括空格。
- 只用真实且相关的词补足长度，不用“优质、完美、理想”等低信息词凑字数。
- `title_keywords` 使用 2–4 个不同且标记为核心的短语，全部自然进入标题。
- 数量为 1 时 `title_quantity_term` 为空；数量大于 1 时，本地化数量短语紧贴第一个核心产品词或其自然修饰短语之前。
- 把能解释价格、购买或适配差异的 `critical_differentiators` 放在标题前部。层数、加厚、双面、带灯等重要差异可以成为第一个核心产品短语的一部分。
- 普通尺寸、颜色和内部款号移至 Item Highlights；影响适配或选择的重要尺寸可保留在标题。
- `title_scene` 可空；填写时必须自然出现在标题后半部。多个场景不得用 `/` 堆叠。
- 父体只写共用事实；子体只写当前变体。多色套装不枚举所有颜色。
- 不使用 ASIN、竞品品牌、占位符、促销、主观最佳或无法证明的承诺。
- 避免 Amazon 禁止字符与同一实义词无意义重复。大小写、连字符和标点遵循目标语言。

## Item Highlights

- `item_highlights` 必填、单行，最多 125 个字符，目标 115–125。
- 写成一句自然文案，不用 `/`、竖线或连续逗号堆词。
- 优先补充标题未容纳的核心/长尾词、重要尺寸、材质结构、安装适配和多个真实场景。
- 可以重复标题中的关键差异或产品词，但必须增加新的识别信息。
- `item_highlights_reference` 记录直接支持它的开发资料或竞品点位。

## 五点卖点

严格五条，每条使用：

```text
相关 Emoji＋【简洁的本地语言利益点标题】＋2–4 句正文
```

只计算正文时，每条必须超过 200 个可见字符。没有最高字符硬限制，但每句话都要增加具体信息；不能通过重复同义句、场景形容词或免责声明凑长度。

每条先说明具体产品事实，再解释其作用、使用方式、适用条件和买家结果。每条至少覆盖“特点/动作、直接作用、买家结果”中的两层。小标题必须点明具体功能或利益，不用“产品介绍、品质之选、更多细节”等空泛标题。

推荐顺序：

1. 核心差异、主要用途和最重要结果。
2. 尺寸、适配范围或关键选择条件。
3. 材质、结构及对应的实际表现。
4. 安装、使用步骤和主要场景。
5. 包装内容、外观、清洁收纳或另一个购买理由。

同款模式下，第一条同款链接是开发资料未展开内容的主要来源。可以组合同款链接中互补的细节，但每项宣称必须能追溯到具体点位。包装点说清实际包含物；尺寸点说明测量部位和适配边界；材质点说明可感知表现；使用点写清操作对象与动作；场景点说明产品在场景中的具体作用。

买家文案中不得出现“资料显示、已确认、同款竞品、审核、与标题一致”等内部语言。评论只能帮助安排信息优先级，不能直接转写成自有产品承诺。

## HTML 详情

只使用 `<p>`、`<br>`、`<b>`，顺序如下：

```html
<p>2–3 句产品概述。</p>
<p><b>本地语言功能标题：</b><br>
1. 小标题：2–4 句详细说明。<br>
2. 小标题：2–4 句详细说明。<br>
3. 小标题：2–4 句详细说明。</p>
<p><b>本地语言产品参数：</b><br>
材质、颜色、尺寸和测量部位</p>
<p><b>本地语言使用/保养：</b><br>
有可靠事实时填写。</p>
<p><b>本地语言包装内容：</b><br>
数量 × 实际物品</p>
<p><b>本地语言注意事项：</b><br>
确有事实时填写。</p>
```

- 概述说明产品是什么、核心结构、搭配方式和主要场景，不写空泛口号。
- 编号功能为 3–5 项，每项 2–4 句，详细说明特点、材料/结构、使用方式、解决的问题、买家结果和必要边界。
- 参数写清测量部位、数值和单位。
- 使用/保养块可选；出现时位于参数之后、包装之前。
- 包装内容逐项列真实数量，场景道具不算配件。
- 注意事项可选；出现时位于包装之后。
- 允许完整展开标题、Item Highlights 和五点的重点信息，不要求机械去重。

## Search Terms 研究与填写

### 候选研究

1. 将第一条同款链接 ASIN 记录为 `primary_reference_asin`。
2. 使用卖家精灵反查该 ASIN 的自然关键词，记录来源站点。
3. 对每个候选短语在目标 Amazon 站点检查前 20 个自然商品，广告位不计。
4. 记录 `organic_results_checked`、`relevant_results` 和 `relevance_band`：占比不低于 70% 为 `high`，40%–69% 为 `medium`，低于 40% 为 `low`。
5. `high` 优先采用，`medium` 按剩余字节采用，`low` 通常排除。结果主要为配件或其他品类时直接排除。
6. 来源站点与目标站点不同时，候选只作语义参考，不声称当地搜索量。

### 最终填写

- 先汇总 Item Name、Item Highlights、五点、详情和 `front_end_attributes` 的全部词元，再从已采用候选中删除前台覆盖词。
- 候选研究保留完整短语；最终 Search Terms 按词元去重，所以不要求保留原短语词序。
- 全部小写、单行、单空格、无标点；不重复词，不写停用词。
- 排除品牌、ASIN、竞品身份、错误规格、无依据功能、主观宣传词、临时性表达和无关流量词。
- 不超过 249 UTF-8 字节。高相关增量词不足时留短，不用泛词填满。

## 审核

- Item Name 68–75 字符，2–4 个核心词均有证据并自然出现；数量、关键差异和变体位置正确。
- Item Highlights 必填且不超过 125 字符，补充了规格、结构、关键词或场景。
- 五点正好五条，每条正文超过 200 个可见字符并包含 2–4 句。
- 详情含 2–3 句概述、3–5 项详细编号功能、产品参数和包装内容；可选块顺序正确。
- 不因前台字段重复核心词、尺寸、场景或卖点而报错。
- Search Terms 的每个词都来自已采用、相关性合格的候选，并且没有在任何前台字段或已填属性出现。
- 数字、材质、功能、包装和变体均可追溯到自有事实或“同款确认＋具体竞品点位”。
- 连续 8 词与竞品相同只提示人工复核，不自动判定抄袭；同款事实可以重复，竞品品牌和身份不得出现。
