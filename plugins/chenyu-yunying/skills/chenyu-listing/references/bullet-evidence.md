# 五点取材与去重

用于生成、重写或审核五点。严格参考指内容与实际读到的原始卖点对应，按本品事实校正并用目标站点语言重写，不是逐句照抄，也不是只借标题、看图后自行扩写。继续遵循原有事实证据、字段格式与长度规则。

## 写作前：从参考形成五个信息主题

1. 通读用户全部有效参考的原始五点。按 ASIN、站点、第 N 点和原文摘取独立信息，合并多链接的同义卖点。每个链接都可以贡献核心卖点或展开细节，尽量覆盖各自有价值的信息，不把其他链接降为仅有缺口时才读取的材料；不从“这产品看上去是什么”自由写五段。
2. 本品属性缺失时，默认沿用第一条当前匹配款式的属性；这不限制五点从全部参考取材。只有本品描述确实明确写出实质差异，才改动对应内容；实质差异指会改变产品属性或购买判断的信息，如不同材质、结构、适配对象、售卖数量或规格，而非措辞/篇幅不同。没有明确差异就不重新推演，也不要求本品资料重复证明参考中每条普通描述。首链接明确写出的普通属性按上述默认方式采用，不能自行增加来源没有的材质/性能、舒适度或调节范围；竞品品牌、认证、质保和售后承诺不迁移。保留实际取材来源，不把本品事实核对变成整句来源替换。
3. 在内部 `bullet_outline` 为每条记录 `main_claim`（一句核心信息）、`reference_points`（ASIN/点位/原文）、`supporting_details`（有出处的展开）、`new_information`（区别于其他四条的信息）。另逐链接记录所有有效参考卖点的采用位置及合并/排除理由；不在交付 Excel 新增审核页。
4. 先审核五个核心主题，再写正文。同义卖点只分配一个主要位置；同一来源可支持多个不同事实，多个来源也可支持同一条，不用不同 ASIN 数量代替信息差异。不要求来源原本正好分成同样五条，但其适用核心卖点不能被泛泛外观介绍挤掉。

参考没读到就补研究；参考信息有限时先检查其他已给链接和本品确认资料，仍不能形成五个有实质信息的主题时，说明缺口或所需资料，不捏造五条完整稿。不能靠编一段佩戴教程、礼赠场景或收纳建议填第五条。

## 写作中：每条围绕一个不同的购买重点

开发表只在明确的实质差异处覆盖参考，不作为五点扩写素材。引用原文须支持这句实际表达的含义，不能从部件或外观推出新的作用；例如“掌心防滑点”不支持“方便辨认手套内外侧”。即使有图案、色差或纹理依据，也不把“容易辨认某个部位”作为无来源的独立买点。

每条主体与展开细节可以融合所有有效参考的相关内容，按最小有意义短句分别保留实际来源；本品资料只在明确的实质差异处局部替换。小标题、正文与所挂来源表达同一个主题；不能小标题引用参考、正文全部自行想象。`clause_sources` 保留逐短句映射，`field_fact_ids` 核对本品适用性。来源中只写结构，不代表自动支持舒适、牢固、不易打结或任何由结构推演的使用结果。

先把参考中的有效信息说清，再调整长度。原有长度条件不能授权编造“张开手再弯曲”“让袖子避开”“平放后下次更易识别”等具体动作或结果；只有参考/确认资料明确支持，且能帮助购买或必要使用时才采用。无需为了每个已知属性都写一句利益解释。

五点整体按信息去重，不按词汇去重。产品名称、必要型号或语法词可以再次出现；同一购买理由不能换个标题再占一条。已在第一条讲清的结构，后文只在解释一个确实不同且有依据的特点时简短带过，不重新列全部部件。

## 完稿后：来源、信息差异、语言三次核对

- **来源覆盖**：逐条将主张和展开与真实原文并排核对；所列点位确实支持对应文案，各有效链接的适用卖点已尽量覆盖，未采用项有具体理由；同一句融合多个链接的细节时分别标明，不靠罗列未贡献内容的链接增加覆盖数。仅有链接或引用一句不代表整条有依据。
- **整组去重**：把五条各缩成一句信息摘要，比较是否回答不同的购买问题；再逐句做删除检查。同义复述、部件倒序罗列、无新信息的组成总结应合并或删去。第五条不做前四条总结。
- **本地表达**：按 [欧洲站本地化](europe-localization.md) 使用具体、克制、自然的商品表达。不要把不自然的参考译文当范本；不把“欧洲风格”理解为固定语气或自动添加礼赠、优雅、舒适等词。

典型不合格情形：某条已说明“指环由细链连接腕链”，后面分别以“从手指到手腕”“一件连体饰品”“三个部分相连”重新讲一遍，即使词句不同，也只有一个结构信息。颜色细节、穿搭建议若只是再次描述链条走向，同样没有形成新主题。应回到参考寻找尚未覆盖的有效卖点，而不是替这几段换同义词。此例不意味着其他产品不得写真实的结构、操作或收纳信息。

脚本能检查字段、长度、来源点位和部分文字重复，不能证明五点信息独立、引用语义正确或语言自然。上述核对未完成时，不得仅凭 `ready_for_delivery` 宣称文案合格。
