# 欧洲站本地化

默认综合交付使用 DE、FR、IT、ES 四站；UK 仅在用户明确要求时加入。下表保留 UK 规则，便于按需生成。

| 站点 | 语言 | 特征 | 参数 | 使用/保养 | 包装 | 注意事项 |
|---|---|---|---|---|---|---|
| DE | 德语 | Eigenschaften | Produktdetails | Verwendung / Pflege | Lieferumfang | Hinweise |
| FR | 法语 | Caractéristiques | Informations sur le produit | Utilisation / Entretien | Contenu de l’emballage | Remarques |
| IT | 意大利语 | Caratteristiche | Specifiche del prodotto | Uso / Cura | Contenuto della confezione | Avvertenze |
| ES | 西班牙语（西班牙） | Características | Especificaciones del producto | Uso / Cuidado | Contenido del paquete | Avisos |
| UK | 英式英语 | Features | Product specifications | Use / Care | Package contents | Notes |

DE 检查名词大小写、复合词、语序；FR 检查性数、介词、重音；IT 检查冠词、性数和属性搭配；ES 使用西班牙当地用语；UK 使用英式拼写。所有语言使用自然句式，不模仿示例逐词首字母大写或生硬埋词；逗号、分号和冒号后的空格按当地语言规范处理。

多站点任务先形成一份稳定的英文语义提纲，逐项固定事实、功能、买家价值和限制。若 UK 是目标站点，先完成 UK 文案；DE/FR/IT/ES 按 Item Name、Item Highlights、每条五点和详情信息块分别本地化，不整段直译，并结合各站点可用竞品样本和关键词调整表达。事实必须一致，但句式、关键词和卖点顺序可以不同。UK 不在目标站点时，英文提纲只作内部桥接，不额外交付英国站 Listing。

每个站点优先从当前 Best Sellers 前 50 个相关商品构成候选池；实际只使用能访问、类目相关且身份可核对的独立商品，并披露有效样本数。不主动新增评论痛点分析；已有评论只能帮助调整信息重点，不能作为自有产品宣称的事实来源。

保留原始单位及测量部位，换算用代码，展示按目标语言习惯；不能将直径改成长度或混淆包装尺寸。核实目标站点类目规则后才能判断长度及字段限制，不能把五站视为相同规则。

## 五点的当地商品表达

欧洲站没有一套统一的“欧洲语气”。先从用户参考链接保留产品信息，再根据当前目标站点同类商品的自然用词独立组织句子；其他站点材料可提供事实，不能直接决定当地语序。不得照搬同店重复模板、错误译文或关键词堆砌。

- 用短而具体的特点标题与直接的陈述句，优先讲产品实际属性、适用条件和购买区别。必要操作才用祈使句；不把五点写成一套观察产品或摆放手部的教程，不用“您会发现”“无需再选择”“下次更容易辨认”一类空泛推论。
- FR：使用自然法语商品名称、常用搭配与性数一致的表达；如 `chaîne de main` 的用词应结合实际参考和本品确认。避免反复解释同一饰品从哪个部位通向哪个部位；用准确的属性说明取代反复 `Portez / Regardez / Gardez / Vous retrouverez` 的指导。此规则不禁止有真实用途的安装或操作说明。
- DE：名词、复合词与句子语序自然，具体参数紧邻所描述属性，不把关键词拼成没有语法关系的长串。
- IT / ES：分别使用意大利语和西班牙当地常用的产品称呼、动词搭配和修饰语顺序，不沿用法语或英文逐句结构。
- UK：按需使用自然英式英语，避免其他站点句式的直译。

各语言保留相同的已确认事实与五点核心分工，但不要求句数、词序和句式逐一对齐。中文翻译用于核对，不把中文电商修辞反向直译成目标语言。沿用当前约定的 Emoji/标题和长度格式；自然表达与来源核对另行审核，格式齐全不代表文案合格。
