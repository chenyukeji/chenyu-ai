# 从参考商品提炼有效表达

在完成参考文字阅读、确定当前产品事实后使用。本页补充表达方法，不改变字段长度、语言、同款映射或事实规则。按当前产品选择适用方法；同一卖家或相近模板重复出现的写法，不视为独立验证，也不据此推断销量或转化效果。

## 先提炼有效信息，再学习句子结构

逐条区分：本品可核实的产品信息、可借鉴的解释方法、需要舍弃的宣传或错误。标题学习主产品词和重要差异的前后关系；五点学习如何把组成、动作、条件与用途说清；详情补充参数、部件对应和使用过程。参考标题过长、重复同义词或语言不通顺时，只取其有效词义，不复制长度、语序和堆词方式。

一个有效表达单元通常包含“具体对象/部位＋属性或动作＋必要条件/结果”。根据实际信息选择两三项即可，不要求每句凑齐。例如，有证据时说明开关位于哪个部位、第一次使用要做什么、何种状态表示开启，比“易于使用、轻松操作”更有用。相同动作只解释一次。

## 按产品的购买问题展开

| 产品特征 | 优先讲清的内容 | 避免的替代说法 |
| --- | --- | --- |
| 多件装或主题套装 | 部件分组、每组数量、哪些部件具有核心功能、组合后的实际用途 | 只写总件数；把配件或道具误算进去；反复写“组合丰富” |
| 发光、带电池产品 | 光色/模式、控制位置、首次启用、供电与是否含电池、适用环境的具体边界 | 混写常亮与闪烁；把灯体与电池盒的防水范围混为一谈；把一颗电池或一盏灯的参数套到整套 |
| 穿戴配件 | 发光或可调部位、固定方式、关键尺寸/弹性边界、搭配的角色或活动 | “适合所有头型/年龄”“长时间绝对舒适”等无依据保证；只用模特年龄推定适用年龄 |
| 微缩模型与配件 | 微缩身份、比例或实际尺寸、哪些结构可动、如何放置/固定、包装组成 | 由仿真外观推定真实功能；把展示模型写成可工作的家电；由儿童场景推定玩具适龄 |
| 蛋糕或派对装饰 | 主题与颜色、图案/形状、部件组成、放置或固定方式、实际适用的庆祝场合 | 只列一串节日；把摆拍蛋糕或底座写入包装；由图片推断食品接触安全 |
| 长条灯串、花环 | 每条长度与总条数、灯珠数量所属范围、可弯绕或悬挂方式、供电和布置条件 | 混淆单条与整包总长度；由复杂场景推定一套能覆盖整间房 |

以上是事实收集和表达提示，不是固定五点顺序，也不要求每个产品覆盖每项。有同款映射约定时仍按已有规则组织对应主题，将适用细节补入相应点位。

## 装饰效果可以成为购买理由

对节庆、穿戴和装饰产品，可以描述有具体外观依据的主题效果：光色、表面反光、叶片形状、羽毛质感、图案、配色与真实使用状态。例如从已确认的暖白发光、橡果造型说明秋季装饰用途，从动物造型与叶片组成说明丛林主题。用具体外观支撑效果词，避免每条都重复“营造氛围、成为焦点、留下难忘回忆”。摄影布光、构图层次、镜头和画面留白仍只属于作图要求。

## 详情应解决五点没展开的问题

部件较多时分组列出数量和对应参数；需要操作时写动作与顺序；不同材料分别对应具体部件。展示型微缩物件应明确是模型或装饰。只补已有证据的使用、清洁、收纳和限制，不把“品质好、用途广、理想礼物”改写多遍来形成详情。

交付前核对：标题/五点/详情中的材质、件数、单件与整套参数、运行模式、包装和使用条件是否一致；翻译保留相同动作、部位和边界。参考文字中的数量冲突、模式冲突、材料混称、漏词、重复标题及绝对化性能不继承。需要核实的项目留在事实记录，不能靠流畅改写消除冲突。
