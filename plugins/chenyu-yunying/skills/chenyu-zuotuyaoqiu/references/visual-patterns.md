# 按产品任务选择视觉表达

评估完整参考图册并确定整套视觉方向时使用。以下为可选方法，按产品和每张任务选择；图数与末张四宫格按 Skill 的固定交付规则执行，本文件不另加装饰模板。是否可直接用作 Amazon MAIN 仍执行 Skill 的站点/类目核实规则。

## 从参考图提取五个具体决定

1. 主体：展示售卖整体、单个代表件、关键部位还是实际使用结果？用哪个角度让形状和用途易认？
2. 构图：主体与辅助区谁先被看到；采用上下分区、左右主辅、局部窗口或步骤分区的原因是什么？
3. 色彩：背景、产品和强调色如何形成区分？主题色可来自产品，信息区仍须保证文字和箭头清楚。
4. 材质与光线：怎样表现透明、金属反光、纱网、羽毛或发光状态，同时保持真实轮廓和纹理？
5. 信息：图片增加哪个购买判断，文字标在哪里才与对应对象明确关联？

把这些决定写成最终构图要求；仅写“参考其高级感、配色好看、场景丰富”不足以执行。

## 多参考整合与构图优化

每张选一张主视觉参考确定主要画面方向，比较其余图的构图清晰度、主体突出程度、场景真实感和信息安排，再整合互补内容。允许重新分区、调整主体与局部窗比例、裁切及文字位置；多场景可合为四宫格。一张图可以解释多个相关内容，必须有明确主次。各模块标明参考图片及采用内容，模型增加的配色、光线、排版等直接融入最终画面要求，设计依据留在内部记录。照片不能单独证明未知材质、尺寸或功能。

信息图删掉原图品牌、错误规格或无依据功能后，重新分配该区域：放入本品已确认的尺寸、材料、结构近照，或放大主体与收紧裁切。空白是为主体呼吸和文字清晰服务，不能因删文案留下视觉重心之外的大块空区。交付前将作图要求与主参考并排看，逐项检查主体占比、背景覆盖、色块、文字位置和整体饱满度；没有实际成品时只检查方案，不声称最终图已匹配。

## 可选构图方法

| 当前任务 | 可借鉴的表达 | 关键执行点 |
| --- | --- | --- |
| 零件外形难以说明用途 | 产品主体＋角落完整使用演示，或使用结果主视觉＋清楚的售卖物局部 | 只保留足以理解动作/位置的环境，辅助窗口有明确层级，不裁断关键动作 |
| 小型首饰的外观与佩戴效果 | 颈部/手部佩戴近景作主视觉，再用较远的穿戴画面说明比例与搭配 | 通过镜头取景让小主体清楚，不为展示全链把吊坠缩成小点，不为抢眼放大真实吊坠；近景与整体穿戴图各有任务，避免每张追加同一特写窗 |
| 穿戴后才易理解 | 穿戴效果＋产品独立展示，或主体产品配小幅佩戴示意 | 产品在穿戴画面中可辨认，避免整个人物占满而配件太小；衣服、妆容与售卖配件区分 |
| 成套装饰或微缩套件 | 组装/摆放结果＋分组组成；配件按形状或用途成组 | 组合结果与散件是同一套的两种展示，不暗示额外数量；全套、单件特写和道具分别清楚 |
| 需要说明功能状态 | 同角度的开/关、展开/收起、安装前/后对照 | 镜头、比例和比较条件一致，只改变被解释的状态；不用明显不同曝光伪造性能差异 |
| 需要说明操作 | 局部动作近照＋简短动词标签，必要时分步骤 | 手部、开关、盖子、接点与动作结果都能看清；不以多张完整产品照代替操作证据 |
| 多部件尺寸 | 按部件分组排列，把测量线、数值和数量贴近对应物 | 不把全部部件画成等大，不挤小字；复杂时拆分尺寸任务或把非关键细节移出 |
| 单件尺寸与使用关系 | 尺寸主体＋真实使用/佩戴场景或测量部位近照 | 整合参考并优化分区和密度，辅助区解释尺寸或实际效果；箭头与数字清楚，不用无关特写填空；仅用户明确要求时保留纯尺寸 |
| 材质/结构 | 清楚的产品主体＋少量局部放大窗 | 每个窗口看不同部位或机制，连接位置可辨；圆窗/边框仅在有助阅读时使用 |
| 多用途场景 | 按不同使用方式、承载物或布置位置分区 | 场景提供独立信息；单纯换模特或换背景时不再增加一张 |

## 场景参考主图与四宫格

- 主视觉参考采用完整场景时，保留它的场景关系、主体占比与氛围，以本品准确替换参考产品，并在整幅画面外加一圈四边等宽的纯白边框。明确边框宽度，保持框内画面饱满；白色外框不是把场景背景替换成白底。靠枕沙发与节日暖光只是适用示例，其他产品按实际参考和真实用途执行。
- 四宫格按左上、右上、左下、右下逐格配置独立场景标题，默认使用 1–3 个英文词，用户指定语言时遵从。标题含义对应本格场景，位置与字号层级统一，复杂背景下保证对比；逐格写出准确文字与落点，不能只写“加标题”、只给一个总标题或因参考无字而省略。

## 主体、色彩与排版

- 从产品颜色及用途确定主题色。暖金、粉色、绿色或黑紫等只能作为具体产品的设计选择，不扩展为所有商品的统一配方。整套沿用文字层级、边框、局部窗和强调方式；任务不同允许布局变化。
- 文字区与复杂纹理分开，尺寸箭头和短标签保留干净底色或清楚对比。节日装饰集中在边缘或低优先级区域，避免标题、边框、人物、道具同时争夺注意力。
- 主体数量与售卖数量有意安排：主图或组成图交代整套，细节图可展示代表件。排布可用前后错落或疏密关系，但不机械复制同样大小的物体铺满；也不因漂亮构图漏掉关键配件。
- 近看用于判断材质和结构，远看用于判断使用效果；整套适当改变观察距离，避免每张都是全景或每张重复放大同一部位。
- 标题点明当前图的具体信息，如操作、部件、模式或尺寸；短标签贴近对象。参考图的错字、混合语言、不对应的标签及无证据功能图标不继承。文字语言按任务要求统一。

## 这类参考尤其需要校准

- 发光产品可用较暗环境突出光色，但仍要保留产品轮廓、接线和材质；发光范围、亮度、反射与实际光源一致，不把微型装饰灯画成照亮大房间的灯具。
- 微型产品、穿戴配件、灯串与环境保持可信比例。手指、身体、蛋糕、家具只在尺度有依据时提供参照；不能单凭参考摆拍反推出尺寸或适配。
- 灯串或多件套的复杂场景须按真实长度、数量与安装方式可实现；若展示额外多套，任务中明确说明，不暗示单套即可达到该覆盖。
- 效果图与组成图互补。蛋糕装饰、微缩洗衣场景或穿戴造型的完整效果有价值，但需让人认出售卖的是哪些物品，不把整个场景当作包装内容。
- A+ 可借鉴横向叙事和场景层次；与图册重复的图不因来自 A+ 再用一次。
