# 作图要求模型规则

将产品事实、参考图片和用户需求转成可执行的逐张作图要求。先做视觉判断，再写最终方案；方案要让出图模型理解画面重点、共同风格和允许优化的部分。

## 产品准确与参考设计分开

先实际查看本品素材和主参考，逐张区分两类约束：
- **产品必须一致**：当前款式/变体的印花、文字、图案方向与位置、结构、颜色、材质、比例、正反面、配件及售卖数量，以匹配实物照片和已确认资料为准。同类竞品只提供表现参考，不能作为本品细节的证明；机位变化不能靠虚构背面或连接结构完成。
- **画面可重新设计**：人物身份与穿搭、动作、背景环境、道具布置、机位、景别和产品摆位，默认可以换成用途合理、氛围与风格相近的新方案，无须与参考图一致。保留参考有效的产品展示关系、信息目的和视觉层次，避免复制同一人物、同一场景布置及同一取景。按任务要求选择变化，不要求每张把所有元素全部换掉。

“参考图片”、描述简略或没有逐项写出变化，均不等于要求复刻。只有用户明确指定同一人物、背景、机位或复刻布局时才将对应元素锁定。用户只要求局部精修、仅加白框或步骤对比时，保留未要求修改的内容与对照所需的一致性，不擅自换人换景。

将“产品固定项”“用户明确保留项”“本张变化方案”直接带入执行文字和生成输入。产品图负责商品身份与细节，场景参考负责用途、氛围和表现方法；同一图片承担多种角色时明确区分。新设计不增加无依据的产品功能、配件或适用人群。

逐张写清以下四项，并直接带入最终执行文字和生成输入：
- 背景：借鉴哪张参考的什么氛围与层次，最终采用的环境、光线、布置与位置；可用类似场景，不照搬原背景。
- 配色：采用相容的背景色、主色和强调色，明确落点并统一整套风格；产品真实颜色保持准确，不为配景改色，不统一套白灰底。
- 字体：借鉴适用的字形风格、粗细与层级，设计清楚的字号、字色和位置；能确认字体名才写名称，不编造精确字体或默认黑色大粗体。
- 标签形式：借鉴适用的色条、圆角牌、胶囊、圆形标记、描边、反白字、引线等表现方式，按新布局确定形状、底色、边框与位置。细节窗保留有价值的观察尺度和信息，不机械照抄每个装饰。

普通单张场景图可不加重复总标题；能由画面说明、且没有新增信息的标题不必添加。无新增文字时明确写“上图文字：无文字”，字体和标签项写不新增；产品本身的真实印刷仍保留。四宫格继续每格一个独立场景标题，沿用参考的字体和标签形式，不另加重复总标题。

四宫格参考已有中央圆形产品展示区时，保留适用的圆区设计；参考没有时，仅在有助辨认产品整体、补充四格中难以看清的本体时加入。圆区是产品展示叠层，不是第五个场景，不增加成品张数；写清圆的位置、相对直径、底色、描边和产品朝向，不能遮住四格标题、关键动作或主要使用关系。无需展示时不机械加圆。

## 决策顺序

1. 保留用户最新明确要求和已确认产品事实：款式、颜色、图案、结构、比例、尺寸、售卖数量及准确文案。
2. 分清用户指定的限制与模型提出的设计。用户指定的位置、数量或禁用元素必须保留；未写细的取景、背景、装饰、布局和文字落点可重新设计，保持用途合理和整套风格相容。
3. 主图先锁定第一条竞品链接对应变体的主图，保留有效展示内容与关系，模特、场景、机位和布局可换成类似风格的新方案；其他图片同样借鉴表达方法和信息层次，不要求复刻构图。
4. 参考图提供表达方法，产品资料提供商品事实。季节氛围、光线风格和装饰可借鉴参考，环境布局与具体元素可调整，不需要虚构商品证据。

## 先确定整套风格

为每个产品确定共同主题、背景色与强调色、光线、材质表现、字体层级及装饰形式。风格适配产品真实颜色；不要给产品改色来迁就背景。

主题不限于节日。先提取主要参考的氛围元素与表现方式，保留适用的层次和丰富程度。以下也可用于替换参考场景中的具体元素，不要求给简洁画面额外堆装饰。

| 主题示例 | 可选择的环境与元素 |
| --- | --- |
| 夏日泳池 | 池水、水面光斑、阳伞、清爽色系 |
| 海边 | 沙滩、海浪、海滨植被、自然日光 |
| 秋季 | 黄色或金色叶片、枝条、暖阳 |
| 春日花园 | 花草、绿植、柔和自然光 |
| 圣诞 | 松枝、树饰、暖灯、缎带 |
| 万圣节 | 南瓜、蝙蝠剪影、主题灯光 |
| 派对 | 气球、彩带、纸屑、活动布置 |

这些是启发，不是固定清单。已有适用参考时借鉴其主题，具体环境和元素可替换为相容方案；缺少参考时按本品用途设计。各图可以变化元素数量、位置和取景，但沿用同一色系、材质、光线和表现风格。写实、插画与图形可以有计划地结合，避免随机混搭。前景、背景和边角均可放元素，保持产品和文字清楚；环境不暗示未经确认的用途或性能，道具不表达为包装内含物。

## 逐张构图

先确定本张最值得看的内容，再决定镜头距离、主视觉、辅助内容和文字位置。细节图可以直接以材质近景为主画面；场景图可以保留自然的前后层次。参考图的取景、材质光线和空间关系有价值时，将这些优点写进方案。

参考已有的适用分栏、放大窗和装饰分割先保留其展示与层次作用。没有适用参考而需自主规划时，辅助窗用于补充主画面看不到的信息，不默认套用“整只产品＋右侧双窗”。比例只在有助执行时写，注明指画布宽度、高度还是面积；留出主体、标题和标注真正需要的空间。

装饰与信息模块分开判断：装饰可以增加氛围；同部位特写还可能承担观察尺度和版面层次，不因信息相同就删掉参考中的适用窗口。留白用于阅读或衬托主体，空白失衡时调整取景、主体位置或环境层次，不机械加窗口填满。

## 各类图片的关键要求

- 主图：以用户原始顺序第一条竞品链接的对应变体主图为主参考，充分保留展示内容、卖点表达、组合及使用关系，逐项映射到方案；模特、场景、机位和布局可换成相近风格的新方案，保持主参考来源与关键展示内容。只按本品实际数量、外观、配件等修正实质差异，不迁移竞品品牌或无依据宣称。产品成为视觉中心且无文字。采用完整场景参考主图时，保留有效场景关系与氛围，以本品准确替换参考产品，在整幅场景外加四边等宽的薄纯白框，并写明宽度。明确要求只加白框时保留原场景；白底主图保持纯白。不要用竞品图片证明平台合规，只有要求可直接上传 MAIN 时才核实站点类目要求。
- 细节图：用合适角度、侧光和裁切表达真实纹理、起伏或结构。参考的适用细节窗保留位置、形状与层次，说明观察尺度或结构展示作用；新增窗口才按新增信息需要安排。
- 尺寸图：标注真实测量部位与独立方向，使用 cm / in 双单位，英寸按厘米÷2.54换算并默认保留两位小数。默认标题 Product Size，标题和箭头保持次级层级。数值可读只是基础；还需表现产品形态、相关的使用关系及整套视觉风格。按本品选择平铺测量、同场景测量或主辅组合，不默认把尺寸图做成产品轮廓加两条箭头。用户指定纯尺寸时遵从。
- 四宫格：每产品末张恰好四格，场景真实适用且有区别。按左上、右上、左下、右下写清画面；每格都有独立标题、准确文字和落点，默认精简英文，用户指定语言时遵从。总标题不能代替四个分格标题。

尺寸图的参考取舍和设计理由：
- 分别评估商品数据与视觉表达。竞品尺寸、数量或材质不适用时，替换或删去这些信息，仍可借鉴其有效取景、色彩、光线、装饰与层级；不以数值不同为由否定整张参考的构图。
- 对平铺后难以理解用途、穿套关系或覆盖效果的产品，优先用有依据的使用状态补充理解。示意穿戴或使用关系不等于宣称适配所有对象；保持合理比例，不新增适配范围，也不把平铺尺寸直接标到透视中的未知部位。
- 辅助信息与主题装饰分别取舍。没有必要增加局部窗，不等于要删除光影、材质层次或与整套相容的环境氛围；装饰保持从属，不挤占测量端点和数字。
- 选择简洁单主体时，说明本品为何无需额外使用说明，以及取景、光线和排版怎样形成清楚的视觉层次。“只有两个尺寸”“箭头已清楚”“场景不能证明适配”不能单独作为充分理由。也不强制每张加场景、加小窗或固定分栏。
- 将选定方案写成正向画面要求，区分用户明确禁用项与本次设计取舍；不要把“简洁”“不堆砌”扩写为禁止一切场景、装饰和辅助内容。

未说明张数时每产品默认7张不同任务，主图第一、四宫格最后；用户可明确调整张数，按指定数量安排中间任务，不自行改为6张或8张。共用设计不代表外观不同的变体可以共用一张成品。

## 多场景方案的差异与重复检查

规划四宫格或其他多场景拼图时，逐格交代使用目的、环境布局、远中近景、机位与拍摄角度、产品朝向和画面位置；有人物时再交代适用年龄范围、发型穿搭、动作、身体朝向与视线对象。采用不同机位和景别来说明不同使用关系，不把“场景不同”简化为四个地点名称。各格沿用共同配色、字体和产品外观，构图不必相同。

- 同一产品可以出现多次，但不要安排四个等大居中、同一朝向的产品，或同一个人物换背景。仅镜像、裁切、缩放、换标题和小道具不构成独立场景。远景仍能辨认产品，近景保留必要的使用关系；不同角度不能依赖未知背面、虚构结构或错误的佩戴方式。
- 人物场景区分人物外形、衣着、自然动作和目光，避免同款服装、同侧转头、整齐笑容和统一看镜头。年龄差异只在产品资料支持的适用范围内安排；不要为凑人数或年龄段擅自加入儿童。写实要求具体到自然皮肤纹理、衣料褶皱、真实接触与环境光影，避免只写“不要 AI 感”。
- 背景区分空间结构、家具关系、活动及光线来源，不能反复用同一桌子、壁炉或装饰布局。季节和节庆风格可以一致，所选场景仍需符合产品实际用途，不为追求差异强加无关场景。
- 步骤演示、前后对比、连续动作或用户指定同一人物/机位时，保留对照需要的一致性，不为去重破坏表达目的。字体、色彩、标签与细节窗保持整套风格，布局可随新的机位和动作调整，不为去重破坏信息层次。

交付前同时比较四格和整套图片：遮住标题后是否仍能辨认场景区别，每格是否提供新的使用判断，是否反复套用同一主体位置、同角度摆放、同一人物姿态或重复放大窗。重复方案先改为有具体用途的不同取景；无需额外拆图、增加格数或强制每格单独生成。相似布局确有比较价值时保留，并说明用途。此处核对的是作图方案，不宣称已经检查生成成品。

每格的最终画面安排直接写入 `scene_cells[].output_scene`，并按左上、右上、左下、右下完整带入 `instructions` 和 Excel G 列；独立标题仍放 `output_text` 与 `on_image_text`。不要仅在内部设计记录写差异、交接时又缩回“四个不同场景”；摄影指导与重复检查说明不作为上图文案。

## 写成出图模型能够执行的文字

每张交代：适用产品和成品数量、本张目的、参考图实际贡献、最终画面、准确上图文字及位置。只有用户确实指定时，才单列“用户固定要求”；其余写成“画面方案”，出图模型落实最终画面方案与产品固定项；没有明确锁定的人物身份、背景细节和机位可在类似风格内调整，用户明确布局与文字要求不变。

最终画面写具体主体取景、场景关系，并逐张写清背景、配色、字体和标签形式及对应参考、位置；无新增文字时明确说明。不要只写“高级感、氛围感、风格统一”，也不要把同一布局重复描述几次。相同风格可以沿用，但每张仍须包含出图所需的具体视觉信息。

图片固定1254×1254 px、1:1。不输出独立“画面密度”“设计优化”“验收”段落；保留“上图文字”，没有文字时写“无文字”。内部记录商品来源与设计依据，交付方案保持直接可执行。

交付前检查：产品固定项是否准确、画面变化是否合理且区别于参考、参考贡献与最终方案是否写清、主体是否突出、装饰是否相容、文字是否清楚、各图信息是否重复、用户固定要求是否保留。结构校验不能证明构图好看。
