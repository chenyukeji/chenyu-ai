# 晨玙作图要求

读取 [开发文档读取规范](../../references/kaifawendang.md)，复用已确认产品事实。已有 Listing 时核对卖点一致性；没有 Listing 也可独立规划，不强制先写文案。

同一任务已有 `competitor-research.json` 时读取其中 visual_evidence、原始商品链接和图片 URL，借鉴信息层级、构图类别和卖点呈现方式，不重复联网抓取。用户提供竞品链接但尚无研究包且确实要求参考竞品视觉时，先读取并执行 [竞品研究 Skill](../chenyu-jingpin/SKILL.md)。

竞品图片通常只作版式参考；若图片中的产品与当前变体在图案、颜色、结构和规格上逐项一致，可记录匹配依据并作为同款产品视觉参考，供美工观察完整外观或细节。即使判定同款，也不能把竞品文案、品牌、配件、尺寸或功能声明自动写成自有产品事实。

## 图片规划

先确定每张图要完成的销售任务，再按任务查找最匹配的竞品参考图。不能因为当前素材里有什么就反向决定图序、图片类型或卖点；素材只用于确认产品身份、外观和可执行性。用户没有另行指定图数或顺序时，默认规划七张：

1. 第一张主图：纯白背景、完整展示售卖产品、无文字。
2. 第二张产品近照图：产品细节为清晰主体，默认加入与真实用途一致的使用场景或环境局部，并通过虚化、裁切或明暗层级让场景退居辅助位置；默认无文字。
3. 第三张尺寸图：展示真实测量方向与准确数值；可加入与品类或主题一致的克制边框、角饰、场景边缘或不遮挡尺寸线的细节局部，但中心测量区保持干净；除数值和单位外不加说明性文字。
4. 第四张使用流程图或细节图：产品确有可验证的使用步骤时优先做流程图，否则改为细节图；默认用轻量使用环境、场景边缘或小幅情境窗帮助理解动作和细节，不能削弱步骤/细节主体。步骤优先只用 01/02/03，必须出现动作词时用极短英文，不臆造闭合或安装方式。
5. 第五张产品特点或优势图：只表现已确认且具有区分度的特点，并默认加入少量真实使用场景或环境局部，让买家理解特点在实际使用中的价值；场景不得抢过产品和特点主体。没有可靠或有意义的特点时直接改为完整场景图，不为凑图编造卖点。
6. 第六张场景图：用一个清晰、自然的典型使用场景突出产品。
7. 第七张四宫格场景图：四个有区别的真实使用场景，产品身份和变体图案保持一致；默认无文字。

除第一张白底主图外，第 2–7 张都可以按画面目的融入场景元素。第 2–5 张以“产品/信息为主、场景为辅”，第 6–7 张以场景表达为主但仍要保证产品清楚可辨。辅助场景可表现为淡化背景、环境局部、边框/角饰、桌面或地面关系、人物动作局部或小幅情境窗，不要求每张都做成完整场景大图。场景必须符合产品真实用途和季节主题，不遮挡主体、尺寸箭头或关键细节，不改变产品结构、颜色、图案和比例，也不能让道具看起来像包装内含物。用户明确要求纯净信息图或无场景时，以用户要求为准。

用户明确指定的图数、顺序或图片类型优先于上述默认方案。个别品类确实不适用某个槽位时，保留其销售目的并替换为最接近的可执行图型。明确变体专属图、共用布局及能否共用最终成品；图案不同不能把 A 款成品直接当 B 款。

图片能不使用文字就不使用文字。必须使用文字时，除非用户另有明确要求，图片内文案统一使用精简英文，即使 Listing 使用德语、法语等目标站点语言也不改变；单个标签或短语优先控制在 1–3 个词，尺寸图只保留准确数值和单位。

每张任务记录：

- 图号、产品/变体ID、图片类型和画面目的。
- 有事实依据的核心卖点及来源。
- 构图、场景类型与强度（轻量辅助或完整场景）、人物/道具、产品姿态和不可变化特征；非主图需明确场景如何服务当前画面目的。
- 准确上图文字、语言及位置；无需文字时明确无文字，需文字时默认使用精简英文。
- 可访问的参考商品链接或图片直链、素材角色及可借鉴范围。
- 尺寸、测量部位、单位、画幅及输出规格；默认 1:1、1254×1254 px。
- 禁止元素、逐项验收条件和具体缺失信息。

先锁定默认七张或用户指定的任务清单，再从竞品研究包和产品链接中按“主图构图、近照主体、尺寸表达、流程/细节、特点/优势、单场景、四宫格场景”等目的逐张筛选参考。参考例图和竞品 visual_evidence 可借鉴布局与信息表达，不继承其产品规格、商标、配件或卖点，也不要求美工复制竞品图片。区分实际售卖内容与场景道具。缺少自有实拍时，先检查是否存在已核实的同款竞品图；有可靠同款视觉证据即可继续规划，并在参考链接中说明用途。只有缺失信息会导致产品外观或结构被臆造时，才在受影响任务内写明具体缺口，不建立通用“待补素材”区。

尺寸绑定真实测量部位，cm/in 按 2.54 换算。衔接当前美工流程时英寸保留两位小数，各测量方向单独注明箭头与标签；圆形产品标直径，不强行编出长宽。未给画幅时默认 1:1、1254×1254 px，并标明这是制作规格，不冒充平台通用要求。声称可直接上传前须核实适用站点类目要求。

## 交付给美工

默认交付完整逐图作图表，不能只给泛泛视觉方向。用户提供参考工作簿时优先沿用其有意设计的任务顺序；没有指定模板时，读取并执行 [Excel 交付结构](references/excel-delivery.md)，默认生成“产品内容”和“作图要求”两张工作表。每张成品图使用一个清楚的任务区块。工作簿不新增“审核说明”页，不嵌入参考图或产品图，不设置“补充说明”或独立“自有产品素材”栏；把可访问的自有素材链接与同款/版式竞品链接统一放入参考例图列。

保持美工所需内容清楚：作图要求、参考链接和产品事实。优先写 Amazon 商品链接或图片直链；只有美工与运营共享同一任务目录时才使用本地文件链接。每条链接注明“同款产品”“版式参考”或“自有素材”，避免混淆。未提供参考图时用文字说明，不编造链接。

交付前逐图检查卖点依据、变体对应、文字、尺寸、参考链接可访问性以及链接与任务区块的对应关系；同时检查场景是否服务当前图片任务、是否抢主体、遮挡尺寸信息或造成包装内容误解。下游 chenyu-zuotu 可按这些要求执行，但本 Skill 不强制安装美工插件，也不自动出图。
