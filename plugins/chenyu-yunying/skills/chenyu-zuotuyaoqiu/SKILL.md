# 晨玙作图要求

读取 [开发文档读取规范](../../references/kaifawendang.md)，从开发 Excel、已确认产品事实、自有素材、参考商品链接及竞品视觉证据独立规划图片任务。

开始执行会生成文件的任务前，先读取并遵循 [输出目录规范](../../references/output-paths.md)，本 Skill 使用 `image-brief` 交付部分。

同一任务已有 `competitor-research.json` 时读取其中 visual_evidence、原始商品链接和图片 URL，借鉴信息层级、构图类别和卖点呈现方式，不重复联网抓取。用户提供竞品链接但尚无研究包且确实要求参考竞品视觉时，先读取并执行 [竞品研究 Skill](../chenyu-jingpin/SKILL.md)。

## 产品与参考证据

先按开发文档最后一张产品详情表的变体名称和产品主图/实拍图确定当前产品，规格读取同一变体行；不因前面确认页或供应商款式名称不同暂停。交付的产品名称原样使用该行“变体/变体名称”单元格文本（标准三表开发文档为第三表），产品内容页与作图要求页保持一致；不自行添加颜色、款式、品类前后缀或括号说明，外观补充放规格或执行文字。以该主图锁定外观和结构，其余图片只补充缺口。产品身份图片缺失时按自有主图（含开发 Excel 嵌图）→对应规格供应商图→已确认同款参考主图选择；最后一类可来自任一有效链接，须记录同款匹配依据。仅外观相似不能证明尺寸、材质成分或功能相同；这些事实须有对应规格的资料、确认依据，或用户明确授权从第一条链接采用当前变体适用的缺失属性。后一种情况先按共享开发文档读取规范补进“产品内容”，在内部保留链接、点位和用户授权，再用于上图数值；不从其他款式或未授权竞品推定。没有可靠身份图片时明确具体缺口，继续规划已有依据的任务，不用普通竞品替代本品。

参考商品链接按站点和 ASIN 去重，逐条核对研究包的 `visual_coverage`、`image_summary`、当前变体主图、完整图册及可读取 A+。开发表嵌图不能替代图册覆盖。漏链接或漏图册时先交由 `chenyu-jingpin` 补研究；部分可读或失败须保留具体范围和失败记录，不假称已完整查看。

第一条链接的完整图册是主要内容和视觉起点。先看完整图册，再比较其余链接的构图、产品突出程度、场景真实性和信息安排，吸收更好的做法。每张成品选择一张主视觉参考确定主要方向，可来自任一有效链接；选图说明它适合本张的具体优点，无须证明首链接不可用。多张图可共同提供细节、场景、优势和设计方法，允许重新分区、调整裁切与比例、组合局部窗或四宫格。记录各来源实际贡献，合并重复信息；未采用图片按实际内容说明原因，不以已有图数或列数批量排除。

所有来源图按实际画面评估，不能按文件编号、文件名或“第几张以后”批量判断变体与适用性。主图也须选择有价值的构图、光线或主体呈现参考；产品内容页已有身份图，不代表主图任务无需设计参考。只有确无适用候选时该任务参考区才可留空，并在内部记录具体原因。最终采用的内容须有事实依据、服务当前画面且不重复。记录原图内容与文字后，可以合并同义信息、舍弃空泛宣传、重复模块或不相关场景，逐项留下取舍原因；保留的信息必须落实到最终 Excel 同行执行文字。多张来源图可共同支持一张成品的不同设计要素，不要求逐张复制其全部模块。

参考图尽量不重复用。只有同一图包含多个独立且有价值、需要分别展示的信息点，才跨任务复用，并记录每次不同的借鉴内容。换裁切或背景重复同一信息不构成理由；不同文件名或链接中的同一图也按复用处理。

## 整套视觉方向

按产品任务选择具体表现方法时，读取 [视觉表达方法](references/visual-patterns.md)，把参考图的主体、布局、色彩、材质和信息安排转化为执行要求。

规划逐图任务前，为每个产品确定一段可执行的视觉方向：背景与产品主色、强调色；主体和文字区的阅读顺序与留白；标题与标签层级；镜头、光线、阴影和材质表现；场景的使用程度。变体可共用方向，但配色须适配各自产品。

比较全部图册后确定前两张的分工和整套视觉语言：主体辨识、取景距离、使用效果与信息深度。模型负责优化主体大小、构图、光线、配色、文字层级与画面衔接，选择更能突出本张重点的布局。换模特身份或头像、场景及文字时保持本品外观与可信使用关系；产品实物比例不能为构图变形。设计选择在内部记录为模型优化，不虚构成来源事实。全套统一字体层级、强调色与图形语言，各图按信息需要变化布局。

### 逐张整合参考并设计成品

每张选一张主参考确定画面方向，再按内容需要吸收其他图片的细节、场景或优势。一张图可以说明多个相关内容，明确一个主画面与辅助模块的阅读顺序，不堆小字或零散卡片。可以调整主画面与局部窗、重设分区、改变裁切和比例，或把互补场景组成四宫格。

先确定本张最值得看的一个主体，再决定是否需要辅助模块。主参考已有清楚的取景、场景层次和材质表现时，保留这些具体优点；重排须说明解决了什么阅读或展示问题，不能为了组合多张参考机械改成左右分栏。逐模块写清：参考图片编号及借鉴内容，采用哪些真实信息，最终放在哪里、占多大、怎样与主画面衔接。比例须注明指画布宽度、高度还是面积，并确保主体、标题、标注和辅助区能同时放下；不把65%/35%或70%/30%当作通用配方。描述最终布局，让美工无需打开原链接即可执行。标题、标签、尺寸线与细节窗贴近对应对象；准确上图文字单列。光线、配色、裁切和排版的具体要求融入最终画面描述，原创设计的依据留内部记录，不声称来自某张参考图。

通过取景、主体大小、光线和文字层级让重点更清楚，不以分区、窗口或内容数量衡量设计质量。无目的空白优先通过调整取景和主体位置解决；留白服务阅读，不为填空重复产品或增加局部窗。尺寸图结合尺寸判断相关的场景或细节，可以在同一使用画面内说明，不强制拆成独立侧栏。可见外观与构图从图像取证；尺寸、材质和功能等宣称另有产品资料或已授权采用的文字依据。

## 图片任务规划

每张写清要展示的产品内容及与前面图片不同的信息。按产品辨识、尺寸、结构、使用效果等实际信息安排顺序。每个产品交付 6–8 张图，对应 6–8 个不同的图片任务；不凑相同信息的画面。该范围按每个产品计算，不限制多产品包的任务总数；共用构图时仍须分别核对每个产品的实际成品数量。

规划结构特写前，确认现有对应款素材确实显示待展示部位；布局参考不能证明本品扣型、背面或连接结构。自行规划的任务若依赖尚未取得的细节素材，先查已有开发资料和对应供应商图；仍无依据时，改用有依据且有新增信息的任务，不把“拍摄前取得实拍”写进可直接执行的作图单。若仍无法形成 6–8 张有依据的图，列明具体缺口，不标为可直接交付；已确认尺寸仍可使用，不因此否定其他已有依据的画面。

主图排第一，最后一张固定为四宫格场景图；中间 4–6 张按要展示的内容安排，不固定近照和尺寸图的顺序。尺寸/适配是重要购买判断时安排尺寸图；相关但数据缺失时保留具体待核任务，不编造数值。单独细节、流程、包装内容和重点场景均按独立信息价值选择。

- **主图**：锁定产品内容页的身份图片及已确认事实。根据参考证据、产品特性和交付用途选择纯白产品、穿戴/使用近景或环境效果，不把“能认出是什么产品”作为默认白底的充分理由。首饰等小型穿戴品可通过颈部、手部等局部取景突出主体与佩戴效果；需要完整使用动作才能理解的产品可用白底主体加角落演示；桌旗等软装可用铺设、垂落、褶皱和环境关系表现质感。采用的参考主图若是完整场景图（如靠枕置于沙发、后景有圣诞树与暖光），默认沿用该场景构图、主体占比、前后层次和氛围，以本品替换参考产品，保留真实款式与售卖数量；只在整幅场景外加一圈四边等宽的纯白边框，不改成抠图白底，也不额外加拼贴、标题或装饰。白框薄而清楚，不压住或裁掉主体；在执行文字写明边框宽度（像素或画幅比例），用户指定宽度时遵从。该规则用于所选场景参考，不强制给原本白底的主图加框。写明选择原因、产品角度、视觉重心及主体与场景关系，主图无文字。缩略图中须快速认出售卖产品与用途，避免等大重复主体、无意义留白、演示被裁断或道具抢主体。交付用途需明确；要求直接上传 Amazon 第一张 MAIN 图时核实站点类目要求，将不适合的场景表达放在后续图，不以竞品上架图证明合规。
- **近照/细节**：清楚展示有购买价值的部位、纹理或结构。纯净背景、局部环境或使用场景按解释需要选择，不强制加场景。与主图或其他细节图出现同一部位时，必须展示不同的结构或判断信息。主画面已能看清的部位不再加同内容放大窗；局部窗只补充主画面看不到的有效细节。纹理图优先让有依据的材质近景成为主画面，用侧光、角度与自然裁切表现起伏；不默认用完整正面产品加两个放大窗。确需局部窗时写清它新增的判断信息、裁切范围和边界，与主画面形成主辅关系，不能把局部窗扩成重复纹理的大侧栏。
- **尺寸/适配**：标清测量部位与同一尺寸的 cm / in，按 2.54 换算，英寸默认两位小数并尊重原始测量精度；圆形标直径，不编造长宽。默认标题 Product Size，用户指定标题或无标题时遵从。标题作为次级信息，写清位置和相对字号；尺寸线、数值贴近测量对象，辅助场景保留足够完整的产品与环境关系。小幅辅助场景须限定位置和范围，不能变成贯穿画面的大侧栏；不为装饰引入占空间的弧形分割、厚重标题底块或过粗箭头。不能只把产品单独放在空底上加尺寸线。整合适用参考并优化分区，在不遮挡箭头、标签的区域加入有依据的佩戴/使用场景、测量部位近照或结构细节，让买家同时理解尺寸与实际效果；明确辅助画面的内容、位置、占比及与尺寸判断的关系，不用无关道具填空。只有用户明确指定纯尺寸图时才按其要求留白，并在内部记录该指令。
- **特点/流程/包装**：每张围绕一个主要主题，可整合多个相关内容，按实际结构、操作顺序或售卖清单组织主体、细节窗与短标签。同主题可合并，信息密度过高时拆开，不为覆盖全部参考而堆模块。
- **场景**：场景应证明使用方法、实际效果或适用环境，产品始终清楚；换地点、人物或背景却没有新增判断信息时合并或删去。主图已经清楚表现的使用效果不再占一张重复展示；使用近景与较远的整体效果可分张，但须分别解决外观辨识与比例、搭配或覆盖关系，不因两张都有人物就误判为重复。
- **末张四宫格场景图**：固定为每个产品的最后一张，恰好四格；四格分别呈现真实、适用且有区别的使用或穿搭场景，每格必须有一个独立的场景标题，即使参考格原本没有文字也须按真实用途拟定；全图总标题不能替代四个分格标题。按左上、右上、左下、右下逐格写清画面、产品位置、准确标题及标题落点，四格标题统一层级、清晰可读且不遮挡产品，标题逐项列入“上图文字”。综合各链接的优质构图，优化四格比例、裁切、配色与标题层级；可从不同参考图选择、重组，或依据自有产品事实补足，不能编造用途。来源四格中未采用的场景及文字逐项说明原因。若无法证明四个场景适用，列明缺口，不用单场景图冒充末张四宫格，也不标为可直接交付。

场景必须符合真实用途与季节，不遮挡关键结构、尺寸或标签，不改变图案、颜色与比例，不让道具被误认为包装内含物。除主图外按解释需要使用精简英文，单个标题或标签优先 1–3 个词或必要数值；用户指定语言时遵从，除四宫格每格必填场景标题外，画面已能说明的内容可无文字。

尺寸、结构和功能事实优先使用自有实测或开发资料，其次为有可靠匹配依据的同款对应规格证据；普通同类竞品只借鉴表达方式。不得迁移品牌、冲突规格/数量/配件、认证、质保或售后。冲突以自有资料为准；同款来源冲突或测量部位不清时写出具体待核项。来源点位保留内部记录，执行文字写准确事实及必要缺口。

## 变体与交付

先判断共用构图，再判断是否共用同一张成品。任务目的、信息层级和执行条件一致时共用任务区块，分别写清适用变体、替换项和实际出图数量。颜色、图案、包装或可见外观不同必须分别出图；仅尺寸不同且画面不显示数值、测量线或可辨认的长短差异，其他可见事实相同时才可共用成品。不能按变体数机械复制作图行或相乘统计成品。

逐图执行文字直接写明：参考了哪些图片的什么内容、最终怎样组合、主体与各模块的位置和占比、相对参考做了哪些优化，再列准确文字、数值、适用变体与成品数量。新包使用 `schema_version=3`：`visual_anchor` 指定本行主参考及方向，`composition` 写最终布局、替换项和内部设计依据，不再生成 `density_plan` 或独立“画面密度”段落；已有内容/文字映射增加 `placement`，具体结构见 Excel 规则。每个有信息的模块保留来源，原创设计决定在内部包记录。第一条不是必须照搬的版式，人物姿态、文字位置、分区和背景均可为清晰表达调整，本品外观、真实比例及使用关系保持准确。输出画幅固定为 1:1、1254×1254 px；写入画幅规格即可，不把像素尺寸包装成“画面密度”。第一张若要求可直接上传 Amazon MAIN，核实站点类目要求，把不适用的场景表达放后续图。来源 URL、ASIN 与详细取舍留内部包，同行 G 列用嵌图编号说明实际参考方式。

交付作图单不另列“画面密度”“设计优化”和“验收”段落，不逐张附加通用模型优化说明或重复款式限制。最终构图直接写成可执行的画面要求；产品款式、颜色、图案和结构的一致性仍在内部核对。保留“上图文字”及其具体内容，无文字时明确写“无文字”。

生成文件时读取 [Excel 交付结构](references/excel-delivery.md)。用户指定模板优先；否则以 [运营交付大母版](../chenyu-yunying/assets/晨玙Amazon运营交付大母版.xlsx) 演示的字段、配色、嵌图与文字颗粒度生成“产品内容”和“作图要求”两表，母版七行不是任务配额。严格复用原模板的工作表、表头位置、A–G 七列、列宽、行高、字体、配色、边框和对齐方式；不得自行增删参考列或增加顶部说明行。整套视觉方向留在内部包，具体设计落实到各行 G 列；参考图直接嵌入对应行 C–F 四栏。未找到有价值的图片时写明确构图，不放占位图。

写入 Excel 前独立运行 `scripts/validate_image_brief_boundaries.py` 校验 `image-brief-package.json`。结构校验通过后，仍需按 Excel 规则复核事实、参考覆盖、语义重复和排版；脚本不判断审美或证明同款真实性。本 Skill 交付作图要求，不自动出图。
