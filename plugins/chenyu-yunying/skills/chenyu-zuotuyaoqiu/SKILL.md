# 晨玙作图要求

读取 [开发文档读取规范](../../references/kaifawendang.md)，复用已确认产品事实。已有 Listing 时核对卖点一致性；没有 Listing 也可独立规划，不强制先写文案。

## 图片规划

根据用户要求、产品特点和已有素材安排图数，不固定七张。分别规划主图、尺寸、细节、场景或其他确实有用的图，避免每张重复同一卖点。明确变体专属图、共用布局及能否共用最终成品；图案不同不能把 A 款成品直接当 B 款。

每张任务记录：

- 图号、产品/变体ID、图片类型和画面目的。
- 有事实依据的核心卖点及来源。
- 构图、场景、人物/道具、产品姿态和不可变化特征。
- 准确上图文字、语言及位置；无需文字时明确无文字。
- 所需素材ID、文件/工作表位置、素材角色及可借鉴范围。
- 尺寸、测量部位、单位、画幅及输出规格。
- 禁止元素、逐项验收条件和具体缺失信息。

参考例图可借鉴布局，不继承其产品规格、商标、配件或卖点。区分实际售卖内容与场景道具。缺少实拍时可完成方案，但须标明哪些任务等待素材，不宣称已经能准确制作。

尺寸绑定真实测量部位，cm/in 按 2.54 换算。衔接当前美工流程时英寸保留两位小数，各测量方向单独注明箭头与标签；圆形产品标直径，不强行编出长宽。未给画幅时可建议 1:1、1600×1600，并标明这是制作建议，非平台通用要求。声称可直接上传前须核实适用站点类目要求。

## 交付给美工

默认交付完整逐图作图表；需要文件交接时生成独立作图单及对应素材，不能只给泛泛视觉方向。Excel 可采用“产品事实、图片任务、素材对应、待确认项”，按内容简化，任务一行对应一张成品。

保持美工所需三类输入清楚：作图要求、参考素材、实际产品图。素材引用应为可访问文件或工作表/图片ID，不能只给无法取得的本机路径。未提供参考图时用文字说明，不编造素材。

交付前逐图检查卖点依据、变体对应、文字、尺寸和素材缺口。下游 chenyu-zuotu 可按这些要求执行，但本 Skill 不强制安装美工插件，也不自动出图。
