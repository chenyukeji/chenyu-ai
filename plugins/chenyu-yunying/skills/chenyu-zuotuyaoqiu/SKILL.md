# 晨玙作图要求

读取 [开发文档读取规范](../../references/kaifawendang.md)，从开发 Excel、已确认产品事实、自有素材、参考商品链接及竞品视觉证据独立规划图片任务。

开始执行会生成文件的任务前，先读取并遵循 [输出目录规范](../../references/output-paths.md)，本 Skill 使用 `image-brief` 交付部分。

同一任务已有 `competitor-research.json` 时读取其中 visual_evidence、原始商品链接和图片 URL，借鉴信息层级、构图类别和卖点呈现方式，不重复联网抓取。用户提供竞品链接但尚无研究包且确实要求参考竞品视觉时，先读取并执行 [竞品研究 Skill](../chenyu-jingpin/SKILL.md)。

## 产品与参考证据

先按开发文档最后一张产品详情表的变体名称和产品主图/实拍图确定当前产品，规格读取同一变体行；不因前面确认页或供应商款式名称不同暂停。交付的产品名称原样使用该行“变体/变体名称”单元格文本（标准三表开发文档为第三表），产品内容页与作图要求页保持一致；不自行添加颜色、款式、品类前后缀或括号说明，外观补充放规格或执行文字。以该主图锁定外观和结构，其余图片只补充缺口。产品身份图片缺失时按自有主图（含开发 Excel 嵌图）→对应规格供应商图→已确认同款参考主图选择；最后一类可来自任一有效链接，须记录同款匹配依据。仅外观相似不能证明尺寸、材质成分或功能相同；这些事实须有对应规格的资料、确认依据，或用户明确授权从第一条链接采用当前变体适用的缺失属性。后一种情况先按共享开发文档读取规范补进“产品内容”，在内部保留链接、点位和用户授权，再用于上图数值；不从其他款式或未授权竞品推定。没有可靠身份图片时明确具体缺口，继续规划已有依据的任务，不用普通竞品替代本品。

参考商品链接按站点和 ASIN 去重，逐条核对研究包的 `visual_coverage`、`image_summary`、当前变体主图、完整图册及可读取 A+。开发表嵌图不能替代图册覆盖。漏链接或漏图册时先交由 `chenyu-jingpin` 补研究；部分可读或失败须保留具体范围和失败记录，不假称已完整查看。

先查看全部来源图并记录可借鉴内容，再规划任务和选图；不能先固定成品与参考图清单，再给剩余图片补舍弃理由。从全部链接按任务择优，但每张成品先选一张最贴合本品和该任务的主视觉参考图作为版式锚点；用户指定主要参考链接或原图时优先从中选择，确实不适合才改用其他来源并说明原因。其余参考图只补充适用的产品细节、场景元素或短文案，不把多张图的构图平均混成新模板。清晰、相关且有独立构图、排版、色彩、细节或场景价值的参考图尽量都用上；不因已有参考图、预设图数或 Excel 列数漏选。只有展示内容与设计用途均重复的近似图才择优留一张，并指明与哪张已采用来源图重复、保留图好在哪里。同一张成品可分别借鉴多图的取景、光线、比例或细节；成品信息去重不能变成每张成品只配一张参考。未选图须按实际内容写具体原因，不用“重复或其他变体”“A+ 无新增价值”等通用理由批量排除；其他字母或品牌文字不妨碍借鉴其中适用的构图。

所有来源图按实际画面评估，不能按文件编号、文件名或“第几张以后”批量判断变体与适用性。主图也须选择有价值的构图、光线或主体呈现参考；产品内容页已有身份图，不代表主图任务无需设计参考。只有确无适用候选时该任务参考区才可留空，并在内部记录具体原因。最终采用的内容须有事实依据、服务当前画面且不重复。记录原图内容与文字后，可以合并同义信息、舍弃空泛宣传、重复模块或不相关场景，逐项留下取舍原因；保留的信息必须落实到最终 Excel 同行执行文字。多张来源图可共同支持一张成品的不同设计要素，不要求逐张复制其全部模块。

参考图尽量不重复用。只有同一图包含多个独立且有价值、需要分别展示的信息点，才跨任务复用，并记录每次不同的借鉴内容。换裁切或背景重复同一信息不构成理由；不同文件名或链接中的同一图也按复用处理。

## 整套视觉方向

按产品任务选择具体表现方法时，读取 [视觉表达方法](references/visual-patterns.md)，把参考图的主体、布局、色彩、材质和信息安排转化为执行要求。

规划逐图任务前，为每个产品确定一段可执行的视觉方向：背景与产品主色、强调色；主体和文字区的阅读顺序与留白；标题与标签层级；镜头、光线、阴影和材质表现；场景的使用程度。变体可共用方向，但配色须适配各自产品。

先并排查看有效参考商品的第一、第二张图，判断主体是独立产品、穿戴/使用近景还是整体效果，以及两张图在取景距离、主体占比和购买判断上的分工。参考图适合本品时按“以图改图”写要求：保留主参考图的画幅分区、取景距离、主体位置与占比、人物姿态、色块/边框、文字区位置和整体信息密度；优先替换商品、模特身份或头像、背景及不适用文案，再从其他链接填入有依据的细节。改变其中任一主要版式元素时说明为什么，以及调整后的占位方式。多个同款链接的主图采用一致展示方式时，先沿用这种方式组织本品主图；不能只因通用白底习惯改成另一种展示。参考图已清楚证明适合本品的表现方式时优先保留；改变主图类型或前两张分工须有具体产品依据，不能只借颜色、光线却丢掉核心构图。再从好参考图中提取具体设计方法，写成最终画面要求，例如主体倾斜方向、局部窗比例、文字分区、柔光表现和道具位置。避免只写“高级、精美、参考竞品”。保留主参考图的满幅照片或紧凑图文节奏；删除原图人物、品牌或模块后必须用本品画面、信息或裁切重新占据其位置，不留下大块无目的空白。做一次缩略图检查，主体仍应是最先看到的内容，文字清晰且画面饱满。全套统一视觉语言，各图根据任务改变构图，不把不同参考图的字体、配色和装饰机械拼接。

### 逐张以参考图构图为底稿

有可用参考图时，先确定这张成品对应的主参考图片，再按原图的画面组织写作图要求。主参考决定主体位置、取景远近、人物姿态、产品在画面中的大小、分区/边框、背景覆盖、文字落点和视觉密度；自有产品事实决定商品外观、尺寸、材质与可展示卖点。其他参考链接只提供可嵌入原版式的局部细节或场景，不另起一套布局。不能把“参考构图”写成只取配色或气质，随后自行改为居中小产品、通用信息卡或大面积空白。

每张执行文字要让美工不打开原链接也能按嵌入的主参考图定位：说明画面是满幅照片、左右/上下分区还是拼贴；产品和人物分别位于哪一侧、占画面大致多少、从哪里裁切；镜头、动作和产品朝向如何；标题、标签、细节窗、边框在什么位置。原图没有的模块不必硬加；原图有的有效模块若因品牌、错误事实或人物替换而删除，则用本品已确认的内容、等量画面或收紧裁切承接原区域。保留参考图中有目的的留白，不把紧凑版式改成空旷模板。非主图在缩略图下若出现大片无目的空白，先沿用主参考的场景覆盖和图文分区；仍显空时，在不改变主体层级的前提下加入有依据的佩戴/使用场景、关键部位近照或与当前卖点相关的辅助元素，并写明放置区域与作用。不能用无关道具、装饰词和重复产品照填空。

只有产品实际形状、可用素材、已确认事实或明确上传要求使原构图无法成立时，才改变主体位置、取景、分区或画面密度，并在同行写清原构图为何不适用、具体改动和改动后各区域如何占位。若主参考图无法为本品提供可执行构图，重新选图；不得在 G 列用“参考整体风格”替代版式要求。

## 图片任务规划

每张先写清买家问题及新增信息：看完本张比前面的图片多知道什么。按产品辨识、购买判断、操作理解等实际优先级排序。每个产品交付 6–8 张图，对应 6–8 个不同的图片任务；不凑相同信息的画面。该范围按每个产品计算，不限制多产品包的任务总数；共用构图时仍须分别核对每个产品的实际成品数量。

规划结构特写前，确认现有对应款素材确实显示待展示部位；布局参考不能证明本品扣型、背面或连接结构。自行规划的任务若依赖尚未取得的细节素材，先查已有开发资料和对应供应商图；仍无依据时，改用有依据且有新增信息的任务，不把“拍摄前取得实拍”写进可直接执行的作图单。若仍无法形成 6–8 张有依据的图，列明具体缺口，不标为可直接交付；已确认尺寸仍可使用，不因此否定其他已有依据的画面。

主图排第一，最后一张固定为四宫格场景图；中间 4–6 张按买家问题安排，不固定近照和尺寸图的顺序。尺寸/适配是重要购买判断时安排尺寸图；相关但数据缺失时保留具体待核任务，不编造数值。单独细节、流程、包装内容和重点场景均按独立信息价值选择。

- **主图**：锁定产品内容页的身份图片及已确认事实。根据参考证据、产品特性和交付用途选择纯白产品、穿戴/使用近景或环境效果，不把“能认出是什么产品”作为默认白底的充分理由。首饰等小型穿戴品可通过颈部、手部等局部取景突出主体与佩戴效果；需要完整使用动作才能理解的产品可用白底主体加角落演示；桌旗等软装可用铺设、垂落、褶皱和环境关系表现质感。写明选择原因、产品角度、视觉重心及主体与场景关系，主图无文字。缩略图中须快速认出售卖产品与用途，避免等大重复主体、无意义留白、演示被裁断或道具抢主体。交付用途需明确；要求直接上传 Amazon 第一张 MAIN 图时核实站点类目要求，将不适合的场景表达放在后续图，不以竞品上架图证明合规。
- **近照/细节**：清楚展示有购买价值的部位、纹理或结构。纯净背景、局部环境或使用场景按解释需要选择，不强制加场景。与主图或其他细节图出现同一部位时，必须展示不同的结构或判断信息。主画面已能看清的部位不再加同内容放大窗；局部窗只补充主画面看不到的有效细节。
- **尺寸/适配**：标清测量部位与同一尺寸的 cm / in，按 2.54 换算，英寸默认两位小数并尊重原始测量精度；圆形标直径，不编造长宽。默认标题 Product Size，用户指定标题或无标题时遵从。不能只把产品单独放在空底上加尺寸线。沿用主参考的分区和密度，在不遮挡箭头、标签的区域加入有依据的佩戴/使用场景、测量部位近照或结构细节，让买家同时理解尺寸与实际效果；明确辅助画面的内容、位置、占比及与尺寸判断的关系，不用无关道具填空。只有用户明确指定纯尺寸图时才按其要求留白，并在内部记录该指令。
- **特点/流程/包装**：每张围绕一个主要问题，按实际结构、操作顺序或售卖清单组织主体、细节窗与短标签。同主题可合并，信息密度过高时拆开，不为覆盖全部参考而堆模块。
- **场景**：场景应证明使用方法、实际效果或适用环境，产品始终清楚；换地点、人物或背景却没有新增判断信息时合并或删去。主图已经清楚表现的使用效果不再占一张重复展示；使用近景与较远的整体效果可分张，但须分别解决外观辨识与比例、搭配或覆盖关系，不因两张都有人物就误判为重复。
- **末张四宫格场景图**：固定为每个产品的最后一张，恰好四格；四格分别呈现真实、适用且有区别的使用或穿搭场景，写清每格的画面、产品位置及必要短标签。优先沿用主参考图的四格比例、布局、配色与信息密度，再替换为本品场景；可从不同参考图选择、重组，或依据自有产品事实补足，不能编造用途。来源四格中未采用的场景及文字逐项说明原因。若无法证明四个场景适用，列明缺口，不用单场景图冒充末张四宫格，也不标为可直接交付。

场景必须符合真实用途与季节，不遮挡关键结构、尺寸或标签，不改变图案、颜色与比例，不让道具被误认为包装内含物。除主图外按解释需要使用精简英文，单个标题或标签优先 1–3 个词或必要数值；用户指定语言时遵从，画面已能说明的内容可无文字。

尺寸、结构和功能事实优先使用自有实测或开发资料，其次为有可靠匹配依据的同款对应规格证据；普通同类竞品只借鉴表达方式。不得迁移品牌、冲突规格/数量/配件、认证、质保或售后。冲突以自有资料为准；同款来源冲突或测量部位不清时写出具体待核项。来源点位保留内部记录，执行文字写准确事实及必要缺口。

## 变体与交付

先判断共用构图，再判断是否共用同一张成品。任务目的、信息层级和执行条件一致时共用任务区块，分别写清适用变体、替换项和实际出图数量。颜色、图案、包装或可见外观不同必须分别出图；仅尺寸不同且画面不显示数值、测量线或可辨认的长短差异，其他可见事实相同时才可共用成品。不能按变体数机械复制作图行或相乘统计成品。

逐图执行文字明确：买家问题及新增信息，具体构图和主体姿态，场景/道具作用，身份锁定，准确上图文字及位置，测量方向与数值，适用变体及成品数量，输出规格和验收条件。每张有参考图的任务在结构化包中设置 `schema_version=2`、`visual_anchor`，指定同一行哪张嵌图是主版式锚点。G 列先写“主参考图片 N：保留……”并点出画幅分区、主体落点/占比、取景与姿态、图文模块位置和密度；再写“替换……”说明本品、模特身份或头像、背景、不适用文字各如何替换；最后按需写“补充参考图片 M 的……”及放入主版式的具体区域。无补充时保持原图有效的简洁；画面明显偏空时，写明补入的有依据场景或细节及其位置、占比；有版式偏离时另写原因和新的占位方式。不能只写“参考竞品”“参考其风格”，也不能只嵌图而不说明如何参考。模特图可换头像或整个人物身份，但保持与参考接近的姿态、颈肩/手部取景、产品佩戴位置和大小；背景可换场景，但保留相近的明暗关系和主体占比。主参考有图文模块时不能删成只有小商品和大片空底。默认 1:1、1254×1254 px，此为制作规格。主图上传规则若与参考风格冲突，明确区分合规 MAIN 图与参考风格副图，不用一张空白图代替整套视觉方向。来源 URL、ASIN 和未采用内容的审计记录留在内部包。

生成文件时读取 [Excel 交付结构](references/excel-delivery.md)。用户指定模板优先；否则以 [运营交付大母版](../chenyu-yunying/assets/晨玙Amazon运营交付大母版.xlsx) 演示的字段、配色、嵌图与文字颗粒度生成“产品内容”和“作图要求”两表，母版七行不是任务配额。严格复用原模板的工作表、表头位置、A–G 七列、列宽、行高、字体、配色、边框和对齐方式；不得自行增删参考列或增加顶部说明行。整套视觉方向留在内部包，具体设计落实到各行 G 列；参考图直接嵌入对应行 C–F 四栏。未找到有价值的图片时写明确构图，不放占位图。

写入 Excel 前独立运行 `scripts/validate_image_brief_boundaries.py` 校验 `image-brief-package.json`。结构校验通过后，仍需按 Excel 规则复核事实、参考覆盖、语义重复和排版；脚本不判断审美或证明同款真实性。本 Skill 交付作图要求，不自动出图。
