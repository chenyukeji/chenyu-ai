# Listing 与作图要求边界

Listing 和作图要求是两个独立成果，只共享事实层，不共享成品文案。

## 共享事实层

先从开发资料、自有图片、用户确认和合格竞品证据形成统一产品事实记录。每项事实包含产品名称、数量、尺寸、材质、结构、功能、颜色、变体、包装内容、真实用途和来源状态。自有资料未展开时，已确认同款竞品可以补充与当前规格不冲突的尺寸、结构、材质表现、功能和使用方式；记录具体 ASIN/图片/字段点位即可，不要求所有信息都重新实测。非同款竞品仍只提供关键词、表达或视觉版式参考。

两个成果只能通过这份事实记录保持一致：

- Listing 使用产品事实、目标站点关键词和竞品文字证据，生成买家可读的搜索与销售文案。
- 作图要求使用产品事实、自有素材和竞品视觉证据，生成画面任务、构图、道具、参考图用途和验收条件。
- 一个成果修改后，不把成品句子直接同步到另一个成果；先判断是否改变了事实。事实没变时，另一个成果不必跟着改写。

## 禁止从作图要求流入 Listing

不得把构图或摄影语言改写成产品卖点，包括画面、构图、镜头、主体占比、留白、前景、背景、近景、远景、视觉焦点、层次、错落、不同高度排布、动态感、避免呆板、场景氛围和参考图用途。

Listing 可以写真实使用位置和操作，例如“约 10.9 cm，可放在书架或桌面”“手脚可弯折，可重新调整为坐姿或站姿”，但不能解释这些动作会让图片更丰富或更有层次。

## 禁止从 Listing 流入作图要求

- 不复制 Item Name、Item Highlights、五点或 HTML 详情的完整句子作为画面要求或上图文字。
- 不按照五点顺序机械安排七张图；图片顺序由买家需要看到的视觉证据和当前素材决定。
- 不为了覆盖 Listing 关键词而添加场景、道具或上图文字；Search Terms 不参与图片规划。
- 不把 Listing 的 200 字符要求、SEO 同义词或目标站点长句带入作图单。
- Listing 只能提供“哪些产品事实更重要”的优先级提示。作图要求必须回到事实来源和视觉证据，独立决定怎样证明该事实。
- 上图文字独立撰写，默认使用 1–3 个英文词或必要数值；不得截取长句、堆关键词或缩写五点正文。

## 交付检查

1. 核对两个成果的名称、数量、尺寸、材质、结构、功能、变体和包装事实是否一致。
2. 单独检查 Listing 是否含作图构图语言。
3. 单独检查作图要求是否复制 Listing 长句、五点顺序或 SEO 关键词安排。
4. 允许两个成果强调不同内容：Listing 解释购买和使用，作图要求规定视觉证明方法。事实一致不等于句子、顺序或信息密度一致。
