# 晨玙 Amazon 选品分析

本 Skill 只完成一件事：**根据用户要求找产品，分析候选并生成开品表格。**

开始执行会生成文件的任务前，先读取并遵循 [输出目录规范](../../references/output-paths.md)。

## 默认行为

1. 读取用户自然语言并识别开品策略。用户明确指定的策略优先。
2. 用户说“新品”“新品榜”或没有说明方式时，使用 E：美德新品榜。
3. 用户没有指定来源站点时，默认同时采集 US 和 DE。
4. E 策略下 Amazon 只作为 ASIN、站点和新品榜名次来源；其他分析字段由卖家精灵按 ASIN 补充。
5. 不论 ASIN 来自实时榜单、历史 JSON 或续跑任务，只要上架日期、Review、售价、BSR、品类、预估月销量或图片为空，都进入卖家精灵补数阶段。单条查询默认最多等待 8 秒，页面明确返回空结果时立即结束；卖家精灵已明确查不到的 ASIN 在同一运行目录中保留结果，普通续跑不重复等待，只有显式刷新时才重新查询。
6. 按站点和 ASIN 合并，不能仅凭标题相似跨站合并。
7. 按 [输出契约](references/output-contract.md) 计算透明得分，降序生成 `开品结果.xlsx`，并把商品图直接嵌入文件。同一图片地址每次生成只读取一次；续跑或重建同一工作簿时，按站点和 ASIN 复用其中已有图片，只补取新增或缺失图片。

派对用品已配置 US/DE 新品榜节点。其他类目若无法自动映射榜单节点，返回明确的待补 URL 状态。

## 运行

```json
{
  "skill_action": "run_discovery_flow",
  "request": "针对玩具类目的派对用品找新品"
}
```

未说明策略时也可直接运行，程序默认采用 E，来源站点为 US 和 DE。已有 JSON 数据可通过 `discovery_paths` 输入，用于续跑或离线复算。

## 交付

每次运行保留原始请求、策略识别、Amazon ASIN、卖家精灵补数、候选池、评分明细和最终 Excel。Excel 按内部得分从高到低排列，最终只展示带颜色标识的“结论”和合并后的“理由”。“产品优点&特征”全部使用中文，不展示英文或德文原标题。图片字节只在内存中处理并写入工作簿，不生成单独图片文件；重复生成时直接复制旧工作簿已嵌入的图片。“缺点”只描述产品不足；“生命周期”表示全年或具体可售月份。

得分只用于排列调研优先级。缺失数据必须写入理由，不得当成零销量或自动淘汰。

## 边界

不处理供应商报价、成本利润、采购、验样、试销、Listing、广告或店铺操作。不绕过登录、验证码或网站访问限制。
