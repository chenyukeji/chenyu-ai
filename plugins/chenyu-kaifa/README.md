# 晨玙 Amazon 产品开发插件

面向 Amazon 产品开发岗位的分析插件，用于把市场、竞品、Review、成本和物流资料转化为可审核的产品机会、产品方案和开发决策。

## 包含能力

- 市场机会和需求分析
- 竞品差异与 Review 痛点整理
- 差异化产品方案和 Product Master
- 成本、FBA 费用、广告预算和利润测算
- 开发、验证、暂缓或放弃的决策建议

## 常见输入

- 关键词、类目和市场数据
- 竞品 ASIN、Listing、销量与 Review
- 产品规格、成本、包装和物流资料
- 目标售价、广告预算和利润要求

## 交付与边界

插件会区分事实、假设和建议，并说明数据来源与关键缺口。它不会自动立项、联系供应商、采购下单或发布商品；缺乏实时数据时也不会把示例或历史资料描述为当前市场结论。
