# chenyu-kaifa 1.1.1 开发状态

核对日期：2026-09-26

## 已完成

- 插件保留 `chenyu-kaifa` 名称，当前子 Skill 为 `chenyu-xuanpin`。
- 支持自然语言识别选品策略、类目和来源站点；未说明策略时默认使用 E：美国站和德国站新品榜。
- 已配置并真实跑通玩具类目的派对用品 US/DE 新品榜。
- 使用插件内部 Python/Playwright 采集 Amazon 新品榜 ASIN、站点、榜单排名、类目上下文和商品主图兜底，不依赖 Browser/Playwright MCP。
- 使用卖家精灵按站点和 ASIN 补充上架日期、Review、售价、BSR、预估月销量、标题和图片。
- J 独立使用卖家精灵“选产品”筛查近60天上架、FBM、达到最低预估月销量的产品；采集后再次逐项核验，生成专用优先级和带证据状态的火爆原因。 页面身份为游客时自动使用 worker 环境变量登录并核验；登录失败保留阻塞原因，缓存的部分结果会重新采集。
- 支持卖家精灵登录状态、原始结果缓存、续跑、缺失 ASIN 查询和强制刷新补数。
- 可直接以 SQLite 只读模式分析采集器提供的 `new_releases.db`，不依赖 MCP、不迁移或反写数据库。
- 已实现数据库最新日、自然日前一日、过去 N 天、首次出现、连续出现、产品类型扎堆和排名上升分析；缺少 `product_seen` 时会把首次出现明确降级为“当前保留快照中首次出现”。
- 数据库不建立产品类型、分组标签或相似度字段；产品扎堆由插件运行时同时比较标题和主图，形成无名称的相似商品组，只返回组内 ASIN 与成对证据，不写回数据库。
- 历史数据库的 `NEW`、`REPEAT`、`RISING` 信号可直接进入现有卖家精灵补数、透明评分和 Excel 流程，并写入标准理由的市场信号段。
- 按站点和 ASIN 合并候选；同一标题不会跨站误合并，已支持数字型十位 ASIN。
- 生成中文产品优点与特征、产品风险、可售生命周期、结论和七段式标准理由。
- 使用 100 分内部评分进行降序排列，Excel 展示“强开、开、条件开、偏弱、观察、不建议”。
- 最终 Excel 包含 15 个业务列，商品图片直接嵌入工作簿，不依赖图片网址或 `IMAGE()` 公式。
- 缺失数据会在理由中说明，不会自动当作零销量，也不会写进产品缺点。
- Skill、插件清单和选品测试通过验证；J 已用卖家精灵 US、DE 可见结果试跑。

## 部分完成

- A：中国卖家同类发现——可导入结构化 JSON 数据，尚未实现网页自动采集。
- 产品优点与特征——已实现中文关键词归类，尚未完整读取五点描述、A+、图片和评论证据。
- 产品缺点——已实现按产品类型生成待验证风险；只有来源数据自带评论痛点时才会使用真实痛点。
- 生命周期——已实现按节日和主题判断可售月份，尚未接入历史月销、BSR或搜索趋势。
- 卖家精灵补数——支持失败保留和手动刷新，尚未实现完善的失败队列、自动重试与退避。
- J 的站外流量和功能创新需要独立证据源；当前自动采集结果会明确标为待验证。游客可见结果或分页截断只标为部分覆盖。
