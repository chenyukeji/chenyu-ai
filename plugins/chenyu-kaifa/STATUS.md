# chenyu-kaifa 1.0.0 开发状态

核对日期：2026-09-20

## 已完成

- 插件保留 `chenyu-kaifa` 名称，当前子 Skill 为 `chenyu-xuanpin`。
- 支持自然语言识别选品策略、类目和来源站点；未说明策略时默认使用 E：美国站和德国站新品榜。
- 已配置并真实跑通玩具类目的派对用品 US/DE 新品榜。
- 使用插件内部 Python/Playwright 采集 Amazon 新品榜 ASIN、站点、榜单排名和类目上下文，不依赖 Browser/Playwright MCP。
- 使用卖家精灵按站点和 ASIN 补充上架日期、Review、售价、BSR、预估月销量、标题和图片。
- 支持卖家精灵登录状态、原始结果缓存、续跑、缺失 ASIN 查询和强制刷新补数。
- 按站点和 ASIN 合并候选；同一标题不会跨站误合并，已支持数字型十位 ASIN。
- 生成中文产品优点与特征、产品风险、可售生命周期、结论和理由。
- 使用 100 分内部评分进行降序排列，Excel 展示“强开、开、条件开、偏弱、观察、不建议”。
- 最终 Excel 包含 15 个业务列，商品图片直接嵌入工作簿，不依赖图片网址或 `IMAGE()` 公式。
- 缺失数据会在理由中说明，不会自动当作零销量，也不会写进产品缺点。
- Skill、插件清单和 14 项选品测试已通过验证。

## 部分完成

- A：中国卖家同类发现——可导入结构化 JSON 数据，尚未实现网页自动采集。
- J：近 60 天 FBM 机会——可导入结构化 JSON 数据，尚未实现网页自动采集和条件筛选。
- 产品优点与特征——已实现中文关键词归类，尚未完整读取五点描述、A+、图片和评论证据。
- 产品缺点——已实现按产品类型生成待验证风险；只有来源数据自带评论痛点时才会使用真实痛点。
- 生命周期——已实现按节日和主题判断可售月份，尚未接入历史月销、BSR或搜索趋势。
- 卖家精灵补数——支持失败保留和手动刷新，尚未实现完善的失败队列、自动重试与退避。
