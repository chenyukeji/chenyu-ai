# 输出目录规范

除非用户明确指定其他保存位置，所有美工任务文件统一写入当前工作空间中的 `chenyu-ai` 仓库：

```text
<chenyu-ai>/outputs/chenyu-meigong/<交付部分>/<YYYY-MM-DD_产品简称>/
```

先定位包含 `plugins/chenyu-meigong` 的 `chenyu-ai` 仓库根目录；若当前目录不是仓库，可检查当前工作空间下唯一的 `chenyu-ai` 子目录。无法唯一定位时先确认路径，不得写入插件源码目录、安装缓存或用户上传文件所在目录。

## 交付部分

| 目录 | 内容 |
| --- | --- |
| `image-production` | 按作图单生成的整套商品图、任务记录和文件检查结果 |
| `retouch` | 精准局部精修后的完整图片 |
| `main-image-optimization` | 主图审美优化后的完整图片 |

任务文件夹使用执行当天的本地日期和简短产品名，例如 `2026-09-20_tree-skirt-120cm`。清理 Windows 不允许的路径字符，产品名无法确定时使用稳定的任务简称，不使用随机长串。一次综合美工任务在不同交付部分下复用同一个文件夹名，便于相互对应。

同名文件夹已经存在且本次是新运行时，依次使用 `_02`、`_03`；只有用户明确要求继续原任务时才复用原目录。先确定真实要保存的成果再创建目录，只评价、诊断或预检时不创建空目录。原始输入不覆盖；能形成本地文件的成品、任务记录和检查结果保存在所属任务目录。若图像工具只能在对话中展示结果，遵守工具保存规则，不编造本地路径。

用户明确指定的输出目录优先于本规范。
