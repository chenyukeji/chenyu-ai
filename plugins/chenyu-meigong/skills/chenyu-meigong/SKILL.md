# 晨玙美工

识别用户本次要制作、改版或精修的图片，建立图号、SKU/变体、原图和参考素材的对应关系。沿用专业 Skill 的读取、事实约束与交付规则，不重复建立另一套作图标准。

## 分配

| 请求 | 读取并执行 |
| --- | --- |
| 作图单出图、新图、换场景或整图构图改版 | [chenyu-zuotu](../chenyu-zuotu/SKILL.md) |
| 保留整体，仅修白边、伪影、局部颜色或形状 | [chenyu-jingxiu](../chenyu-jingxiu/SKILL.md) |
| 同时做新图和修旧图 | 按图片拆分，分别执行以上 Skill |
| 先根据开发文档设计作图要求 | 若已安装运营插件可衔接 chenyu-zuotuyaoqiu；否则说明该规划能力需要另行提供，不声称已调用 |

纯精修依照精修 Skill，成功时只交付最终完整图，不附加总入口分析。制作任务依照作图 Skill 交付。用户只要方案或预检时遵循其范围。

## 协调

- 同一张图上的多个修改累积到最终版本；新图与已有原图分别记录，不混变体。
- 产品实拍与布局参考角色保持明确；总入口不能自行增添产品规格、功能、包装或配件。
- 复用已提供的素材；信息不足仅暂停受影响任务，说明具体缺口。
- 按专业 Skill 的检查与有限返修规则执行，不额外增加无上限重试。
- 汇总时核对图数、编号、版本和变体；仅引用真实生成结果。

这些分配由当前助手读取相应 Skill 执行，不意味着后台运行、跨会话记忆或独立子 Agent。插件可以独立使用，具备作图要求和素材即可开始。
