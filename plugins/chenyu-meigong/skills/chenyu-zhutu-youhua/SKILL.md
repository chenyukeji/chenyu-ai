# 晨玙主图审美优化

## 任务定位

接收一张已有 Amazon 主图，先作出专业审美判断，再实际优化并交付新的完整主图。此 Skill 的核心是主动参与美术决策，不等待用户逐项指出构图问题，也不把检查清单代替成品。

默认直接执行“诊断→决策→编辑→复核”。用户只要求评价或方案时停在诊断；用户要求只返回图片时不附说明。

从素材重新制作主图或整套图片使用 `chenyu-zuotu`；用户已明确指定白边、颜色、形状等局部修改且不希望改变构图时使用 `chenyu-jingxiu`。

## 输入与事实边界

- 完整主图是当前画布和构图基准；先实际查看原图，记录宽高比、产品数量、主体轮廓、包装、配件、文字、Logo、颜色、材质、角度、位置和阴影。
- 用户另给产品实拍、包装展开图或规格时，将其作为产品真实性依据。产品事实与当前主图冲突时，优先使用用户确认和清晰实拍，不能靠审美判断改写事实。
- 可自主改变的是视觉表达：主体在画布中的大小和位置、整体角度、组合层次、留白分配、轻微透视、明暗关系、接触阴影、边缘整洁度和背景质量。
- 不可自主改变的是产品设计和售卖事实：SKU、数量、颜色、结构、尺寸、套装内容、配件、图案、Logo、包装文字和功能。不得为了画面更漂亮而增加道具、装饰、徽章、文字、人物或不存在的配件。

## 审美诊断

不要机械地平均修改所有项目。先找出最影响缩略图吸引力和专业感的核心问题，再选择少量高价值变化。

### 视觉重心与主体张力

- 主体是否一眼可识别，是否被无关留白、次要包装面或重复元素抢走注意力。
- 主体占比是否显得弱小、局促或贴边；视觉重心是否稳定，是否存在头重脚轻、左右失衡或重心下坠。
- 产品最有辨识度、最有质感的一面是否处于主要视线位置；关键结构是否因角度、遮挡或裁切而不清楚。

### 比例、层次与节奏

- 单件产品是否具有清晰轮廓和合理透视；多件套是否有主次、前后、大小和间距层次，而不是机械并排或彼此遮挡。
- 重复产品的节奏是否自然，是否出现拥挤、散乱、过度对称或无意义的空洞区域。
- 组合关系是否让消费者立即理解数量和套装内容，且没有把同一产品误读为额外件数。

### 留白与画布关系

- 留白是否服务主体，而不是平均分布或形成大片死白；四周呼吸空间是否均衡。
- 产品与画布边缘、中心线和其他元素的距离是否有秩序；必要时通过缩放、位移、轻微旋转或重新排列改善。
- 优化后保持完整产品，不为追求冲击力裁掉关键边缘、配件或包装信息。

### 光影、颜色与材质

- 光线是否能表达产品体积、材质和真实表面；高光是否过曝，暗部是否脏灰，颜色是否偏色。
- 阴影应轻、自然并说明产品与地面的接触关系；避免漂浮、重黑、多个矛盾光源或装饰性彩色光晕。
- 纹理、透明度、金属、塑料、布料、纸张等材质需符合实拍证据，不能用统一的“AI光滑感”覆盖真实细节。

### 整洁度与高级感

- 清理白边、灰边、锯齿、抠图残留、脏点、重复纹理和生成伪影。
- Amazon 主图背景保持无色偏纯白 `#FFFFFF`；不能用粉白、暖白、灰白、渐变、纹理或场景装饰代替。
- 高级感来自比例、秩序、真实材质和克制光影，不靠无依据的奢华道具、光效或过度锐化。

## 决策与执行

1. 在内部形成一个主判断，例如“主体过小且双件缺乏层次”或“角度清楚但阴影使产品漂浮”。
2. 选择最多三个相互兼容、收益最高的优化动作。普通审美选择直接决定并执行，不要求用户逐项批准。
3. 只有在产品身份不明、套装数量冲突、包装是否属于售卖内容不清楚或两个方向会改变产品事实时，提出一个最短的必要问题。
4. 使用宿主可用的图像编辑工具，默认优先 image_gen。实际附带完整主图和必要的产品实拍；本地图片在编辑前先查看，并按工具规则使用 referenced_image_paths。
5. 编辑指令同时写明“改变项”和“保护项”。允许为重新构图扩展纯白画布、移动或缩放主体、调整整体角度和阴影；不声称生成式编辑能逐像素锁定未改区域。
6. 默认最多两轮定向返修。第一轮解决主要审美问题；第二轮只修复仍可见的构图、边缘、阴影或产品保真错误，避免反复重画导致产品漂移。

## 复核

编辑后必须把结果与原图及产品依据并排核对：

1. 产品数量、结构、颜色、图案、包装、配件和文字是否保持正确。
2. 视觉重心是否更集中，主体辨识度和缩略图冲击力是否实际提高。
3. 产品占比、留白、边距、角度、层次和间距是否协调，且没有关键裁切。
4. 光影方向是否统一，接触阴影是否自然，产品是否仍有漂浮感。
5. 材质、纹理和边缘是否真实，是否新增AI伪影、错误反射或形变。
6. 背景是否为无色偏纯白，四角和主体外侧是否存在灰粉色污染。
7. 输出是否保持完整画布、合理宽高比和可核实的真实文件规格。

若优化后只是“不同”但没有明确更集中、更清楚或更高级，不能判定通过；保留原图并重新选择更小、更有效的改动。无法在两轮内同时保持产品真实性和审美提升时，交付最佳版本并明确具体限制。

## 交付

默认交付一张最终完整主图，并用不超过三条的简短决策摘要说明主要审美调整；用户要求只返回图片时仅展示最终图。用户只要诊断时，输出核心审美问题、建议优先级和预期效果，不执行编辑。
