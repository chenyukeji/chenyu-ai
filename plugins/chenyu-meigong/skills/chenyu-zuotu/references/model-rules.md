# 作图模型规则

根据产品图片、作图要求和参考图片制作实际成图。理解画面要表达什么，在保持产品事实与用户明确要求的前提下完成构图，并统一整套视觉风格。

## 先区分固定要求与设计空间

| 内容 | 执行方式 |
| --- | --- |
| 已确认产品外观、真实比例、尺寸、数量与准确文案 | 保持准确，不能为了构图修改 |
| 用户明确指定的布局、位置、禁用元素 | 按指定执行 |
| 作图单已明确的内容和展示目的 | 全部落实；保留主辅关系 |
| 未写细的取景、背景、装饰、配色和文字落点 | 参考主要图片或自主设计，直接补足 |
| 模型提出的画面方案 | 保留内容与共同风格，可优化未被用户锁定的具体设计 |

先查看实际产品图和参考图，再决定画面。普通构图不需逐项请用户确认。参考图负责构图与表现方法，不能替代产品尺寸、材质或功能证据。

## 全套采用共同视觉方向

开始制作前确定主题、背景与强调色、光线、材质表现、字体层级和装饰形式。作图单已有方向时沿用；没有时按产品、主要参考图与使用场合自主选择。将共同方向带入每张生成输入，产品真实颜色保持不变。

适合季节、环境、生活场景或活动时，主动加入相容的元素，尽量丰富氛围和层次，不等作图单逐项列出。夏日泳池可用池水、光斑与阳伞；秋季可用黄色或金色叶片与暖阳；海边、花园、圣诞、万圣节、派对等按各自主题选择背景与装饰。这些例子不限制其他主题。

全套元素保持相容的配色、材质、写实或图形表现、光线和尺度感，允许各图变化位置、数量与取景。写实与图形可以有计划地结合，不能逐张随机变风格。装饰可进入前景、背景和边角，只要产品与文字清楚。无文字不等于无装饰；明确纯白、无装饰或只加白框时按指定执行。装饰不改变产品，不暗示额外配件或未经确认的性能。

## 欧洲市场模特选角

本插件默认服务欧洲市场。普通商品图、佩戴与使用场景、多场景拼图、A+ 中需要新增或替换人物时，使用欧洲模特，不使用亚洲模特。将这一选角要求写进每张有人物的生成输入；四宫格逐格落实，不能只在整套说明中提一次。无人物的图片不为满足选角要求额外加人。

供应商图、竞品图或历史作图单中的人物不自动成为指定模特；参考其产品展示关系、姿态和有效构图，新增人物仍按上述选角执行。人物年龄、身体比例与佩戴方式须符合产品有依据的适用人群，不擅自加入儿童或暗示适配所有年龄。

欧洲模特不等于每张使用同一张脸：多场景按下节差异规则安排不同人物、发型、穿搭、朝向、动作和远近景，保留自然皮肤纹理、生活化表情与可信接触关系。用户明确要求保留原图人物的局部精修，不因这条新图选角规则擅自换脸；后续明确的任务选角指令优先。

## 形成可执行构图

1. 确定本张第一眼应看到的内容与主视觉取景。
2. 主图按首链接主图保留内容和展示关系，仅小幅调整；其他图按参考的有效构图或自主方案安排背景、环境层次和主体位置。
3. 只为新增信息使用辅助图或局部窗；材质近景可以直接成为主画面，不默认添加完整正面产品及重复特写。
4. 安排标题、准确文案、尺寸线与装饰元素，使产品先于标题、底块和分割线被看到。

写比例时说明是画布宽度、高度还是面积。作图单比例含糊时选择能保持产品真实比例的可实现布局，记录解释后直接制作。明确指定右下的小图应落在右下，不因装饰改成贯穿整侧的图形。布局未锁定时，可以改变取景与分区，不机械套用固定比例。

## 普通图册图片类型

- 主图：以用户原始顺序第一条竞品链接对应变体的主图为主要参考，实际查看并随本品素材一起传入生成工具；沿用其纯白产品、白底使用演示或完整场景形式。逐项保留展示内容、卖点表达、产品组合与使用关系，仅小幅替换模特、场景和布局；不因自主设计另换主参考或删改关键内容。按本品事实修正数量、颜色、结构与配件等实质差异，不复制竞品品牌或无依据宣称。首链接主图缺失时先从研究包、原始链接和已有素材恢复；确实不可用才记录具体缺口与备用来源，不谎称已参考。用户明确另选参考时遵从。纯白主图按#FFFFFF执行；采用完整场景参考主图时，保留其有效场景关系与氛围，并在整幅画面外加四边等宽的薄纯白框，明确宽度。边框不裁掉产品，也不把场景改成白底。主图无文字。只有要求可直接上传 MAIN 时才核实站点类目要求。
- 细节图：用取景、光线和真实材质表现重点。辅助窗补足主画面看不清的结构，避免重复纹理占据大片区域。
- 尺寸图：准确标注测量部位，每方向独立cm / in双单位，英寸按厘米÷2.54换算并默认保留两位小数。默认标题Product Size，标题与标注保持次级层级。按尺寸判断需要选择单主体标注、同场景测量或辅助图；记录选择理由。仅为新增信息加入辅助内容，已有辅助图要让产品和环境关系可辨。用户指定纯尺寸时遵从。
- 四宫格：一张成品中恰好四格。每格场景不同且真实适用，每格都有独立标题与明确位置；简略作图单漏写标题时按场景补足，默认精简英文，指定语言优先。四个标题均写入生成输入和exact_text，不能用一个总标题替代。

普通图册图片仍为1254×1254 px、1:1；A+ 按 [A+ 执行规则](aplus-production.md) 使用独立槽位规格，不继承本节主图、默认标题或四宫格形式。旧单不再单独使用“画面密度”；其中有效布局信息归入画面安排。若工具无法达到规定规格，如实记录实际尺寸，不把预期数值当成已验证结果。

## 多场景拼图的角度与差异

用于表达不同使用场合的四宫格及其他多场景拼图。共同风格统一配色、字体和产品外观，不统一每格的机位、人物和主体位置。步骤演示、前后对比、同人连续动作或用户明确锁定机位时，保留必要的一致性；单张场景和 A+ 单场景槽位不因此拆格。A+ 本身需要多场景时可采用本节差异原则，但仍按其指定槽位、画幅与文字执行。

生成前逐格写出场景方案，记录在本张任务设计中并实际带入生成输入：格子位置、使用目的、环境布局、景别、机位与拍摄角度、产品朝向和画面位置；有人物时再写人物年龄范围、发型与穿搭、动作、视线和身体朝向。不能仅给四个场景名称或一句“各格不同”。

- 景别与机位：根据展示目的安排远景、中景、近景的组合，以及正面、侧面或斜侧视角；不要四格都用等大的主体、居中位置与同一平视角度。远景中产品仍需辨认，近景保留理解用途的必要环境。无需为了凑齐角度展示无依据的背面或遮住关键产品特征。
- 产品摆放：结合真实使用关系改变画面位置、观察方向与可见范围。同一张产品剪影复制四次、仅缩放裁切、镜像翻转或替换背景，不算四种构图。改变的是拍摄和摆放关系，不能改产品结构、配色、印花、数量或制造左右相反的文字。
- 人物：不同使用场景默认采用可辨认的不同人物与穿搭，分开安排脸型、发型、动作和视线；避免四格同款毛衣、同样笑容、同侧转头或统一看镜头。年龄变化限于资料支持的适用人群，不为丰富画面擅自加入儿童或暗示适配全部年龄。用户指定同一模特时保持身份，通过动作、取景和场景区分。
- 环境：空间结构、家具布置、活动内容和光线来源应能区分；同一节庆主题可保留，不能四格都复用同一餐桌、壁炉、树和灯串，只换标题或小道具。不强行加入与用途无关的室外、聚会或人物场景。
- 写实人物：采用自然互动和生活抓拍的姿态，保留适度皮肤纹理、衣料褶皱及可信接触阴影；写清手部动作、佩戴接触和视线对象，避免蜡像皮肤、整齐复制的表情及悬浮产品。光影与透视相互一致，不能把写实风格称为真实拍摄来源。

生图前横向检查逐格方案：去掉标题后，各格是否仍因环境、景别、机位或动作而可区分；是否反复出现同一个产品轮廓、主体位置或人物姿态。重复的方案先调整，再把每格差异明确写入生成输入；不把这一输入检查宣称为成图验收。用户明确要求返修或视觉检查时，也按这些维度查看指定成图，针对重复格修改，并保留未要求更改的产品和文案。

例如圣诞椅套可组合厨房桌侧中景、有人用餐的斜侧场景、公寓餐区的环境远景、宴会长桌沿线的纵深视角；发箍可结合正面佩戴近景、侧向互动中景和活动环境远景，人物与穿搭按真实适用范围区分。这些是构图思路，不能固化为所有产品都用同一套四格模板。

## 生成与交付

每次实际附带当前任务所需的产品图和参考图，并说明各图角色。生成输入包含本张目的、产品固定事实、共同风格、本张构图与元素、准确文字及禁用项；不要只写图片文件名。使用当前可用图像工具，一张独立成品对应一个生成任务，四宫格算一张成品。

产品事实、主体重心、辅助图位置、裁切、准确文字、尺寸线和整套元素风格在生图前落实到输入。生成成功后仅检查文件存在、可读取、格式、尺寸及交付数量，直接展示或交付；不默认查看成图做视觉复核，不自动局部返修或重复生成，也不记录或声称“视觉验收通过”。用户明确要求检查、返修或重做时，按指定图片和问题执行。

## 尺寸图的设计传递

尺寸准确与画面设计分别落实。测量部位、双单位数值和用户明确禁用项保持不变；“简洁”“不堆砌”不自动等于无场景、无装饰或无光影层次。作图单已明确选择单主体时执行其范围，通过取景、真实材质光线、文字层级和相容的背景完善设计，不擅自添加被用户明确排除的内容。未指定构图、或用户要求优化单调尺寸图时，可结合产品实际用途采用主辅组合或同场景测量；有依据的穿套/佩戴示意不代表适配范围承诺。参考图的尺寸不匹配时采用本品数值，仍可借鉴其视觉表达。把选定的正向方案传给图像工具，不将模型自己的取舍扩成比作图单更严的一串禁令。
