# 制作细则

先按 [作图模型规则](model-rules.md) 决定构图与共同风格；本文件补充工具输入、各产品类型的生图前约束和生成后的文件交付。

## 准备生成任务

一次输入只包含该SKU及当前任务必要的素材。有实拍时优先用清晰原始实拍；参考制作或原创概念按主 Skill 的 production_mode 使用已匹配的产品参考和明确规格，并保留实物待确认项。构图例图提供指定的画面方向、场景或姿势；实际执行逐图整合后的最终布局，可吸收多图优点。一个画面可包含多个相关内容，保持主次与清楚的产品主体。主图借鉴首链接主图的有效内容与展示关系；其他图同样借鉴各自主参考的表现方法与层次。产品细节以匹配实物资料为准，人物、背景、机位和布局可设计类似风格的新方案；描述简略不等于要求复刻，局部精修仍保护未要求修改区域。prompt使用以下信息，无需强行填满每个字段：

- 当前任务类别与目标画幅：普通图册1254×1254 px、1:1；A+ 使用本任务槽位的宽、高及桌面/移动端版本，不回退到方形默认值。
- 每张实际传入图的角色。
- 产品不可变化项：款式、颜色、数量、结构、图案、连接关系。
- 画面安排：主视觉取景、人物数、动作与可见部位；有辅助区时明确位置和边界，比例指画布宽度、高度还是面积。保留主参考的有效层次，避免默认套用左右分栏。
- 人物与市场风格：未指定市场时面向欧美消费者，已指定站点则以指定市场为准。每张有人物的实际生成输入中写明目标市场、适合商品的模特、年龄范围、穿搭、动作、场景与视角；多场景逐格指定。不能仅写“西方风格”或直接沿用参考图人物。无脸原图不因选角默认值擅自加脸或改变裁切。验收依据场景、穿搭、构图及产品保真等可见内容，不推断人物实际种族或国籍。
- 全套共同的主题、配色、光线及元素风格；本张适用的装饰种类、材质或图形形式、位置和与主体的关系。
- 本张背景层次与配色落点，字体的字形风格、粗细、字色、相对字号及位置；标签的形状、底色、描边和引线，明确对应哪张参考。不要统一改成黑色大字或删掉标题底块。
- exact text及位置；普通单张场景无新增信息时可无重复总标题，明确无需文案时不加标题或文字标签；保留参考适用的无字装饰，不借无文字之名简化背景。
- 原文禁止项。
- 自然光影、材质和接触关系等必要写实要求。

内部prompt通常用清晰英文，成品文字必须使用用户指定语言。不得因使用英文prompt把中文/法文/德文成品文字改为英文。

## 按类型执行

以下产品主图、尺寸细节与多场景规则用于普通图册。A+ 按 [A+ 执行规则](aplus-production.md) 的槽位任务、准确上图文字和目标站点语言执行，共享产品事实、素材传入与直接交付流程。

产品主图：先确认首链接对应变体主图及已记录的`main_style`，把该主图作为视觉参考随实际产品图传入；prompt逐项写清须保留的展示内容、组合与使用关系，另列必须一致的产品细节、用户明确保留项，以及模特、场景、机位或布局的新方案及本品实质差异。不能只写“参考风格”，也不能未经用户指定把主参考改成其他链接。`clean_white`采用无色偏纯白背景（`RGB 255,255,255` / `#FFFFFF`），prompt写入主 Skill 的纯白硬约束；`white_with_use_inset`保持白底和醒目的单一产品主视觉，仅在有事实依据时加入完整可读的小幅使用演示；`scene_hero`让产品在真实用途的完整场景中占主导，例如桌旗展示铺设、垂落与自然褶皱，而不是只把图案平铺在桌面。采用完整场景参考主图时，按模型规则借鉴场景表现方式并加四边等宽薄纯白框，记录宽度。生图前安排视觉重心、主体占比、用途辨识度、场景裁切与材质表现，并使缩略图也能辨认主体；不要机械复制等大的同款产品，也不要让餐具、手或容器看起来属于售卖套装。保留真实颜色、数量、材质厚度、结构和长度；不得为了更好看凭空改变产品或照搬参考图中冲突的道具。

贴纸/钻贴：区分可剥离贴片、底纸上的眼睛/眉毛图案、钻石本身；不同款或数量不能混用。匹配额头、眼角等指定位置、皮肤曲面、尺度、方向与遮挡。局部细节在源图不可辨时标记unknown，不自信声称完全一致。

发箍/眼罩/穿戴品：在输入中明确实际接触、头发遮挡、绑带、正反面、弯曲与比例；不把耳边绑带生成在脸上，不把产品印刷变成身体纹身。

横幅/肩带：保留实际字母顺序和印刷文案，不用模糊字符替代；在输入中明确绳子连续、悬挂重力及字母与背面的关系。

剥离/操作图：在输入中明确手指、底纸、胶面和接触点，动作与产品真实结构一致，不凭空演示不存在的结构。

尺寸细节：执行SKILL.md的“尺寸标注与缺失信息补全”，数值、单位、独立长宽箭头起止点和测量部位一致。尺寸图按测量需要选择单主体标注、同场景测量或辅助图，有助理解时才加入使用/佩戴场景或测量部位、结构近照；在输入中说明辅助内容如何帮助理解尺寸或实际效果，安排清楚的主次，保留足以判断比例的产品轮廓。右下辅助场景应落在右下，不能扩成贯穿右侧的弧形装饰区；标题与箭头不过重，参考中的适用细节窗保留观察尺度和版面层次，不因同部位已出现就删除。每个方向均用cm / in双单位，生图前核对换算、轴对应和标签位置，禁止乘法式组合尺寸。缺失规格可采用匹配当前产品的参考图明确尺寸并记录来源，不得继承不匹配的竞品尺寸。准确文字、数值和箭头安排在生图前写入输入；生成后不自动读取文字、复核或返修，不将这些输入要求说成已核验的成图结果。

多场景图：按原文画面数和场景差异执行。 读取并落实 [作图模型规则的逐格差异要求](model-rules.md#多场景拼图的角度与差异)，把每格景别、机位、主体位置及适用的人物、环境差异写入同一次生成输入；保持共同风格不等于复制产品摆放或人物姿态。四宫格逐格落实独立场景标题与位置，简略输入未给标题时按场景补足，并加入exact_text，字体与标签形式沿用适用参考；有必要时可叠加中央圆形产品区，写清尺寸和样式，不遮挡四格标题与关键动作。四宫格可一次生成或分场景后用图像工具拼版，依据复杂度选择；不要强制每格一个调用浪费额度。图片中只出现售卖配件或明确属于场景的道具，礼盒不得被表达为包含包装。

## 完成图片

生成成功后直接交付，只保留文件存在、可读取、格式、尺寸和交付数量检查。无需把成图与布局或主参考并排查看，不自动开展文字、构图、风格或产品细节复核，不发起自动局部返修、两轮返修或额外重生成。

任务记录保存真实输出路径或展示引用、文件检查结果、已有产品待确认项和已知工具限制；不填“已对照对应行检查”“构图通过”或“视觉验收通过”。文件属性通过只代表可以交付，不代表视觉内容已经验证。用户随后明确要求检查或修改时，再按用户指定的范围看图并处理，保留原始产品素材作为依据。
