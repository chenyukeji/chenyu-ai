# chenyu-ai

## 晨玙科技 Amazon AI 全自动化运营系统

`chenyu-ai` 是晨玙科技面向 Amazon 跨境电商打造的 AI Operating System（AI 运营操作系统）。

目标：将亚马逊运营从人工驱动模式升级为 **AI Agent 驱动模式**。

系统覆盖：

- 市场分析
- 自动选品
- 竞品研究
- 产品开发
- Listing 创建
- 图片内容规划
- 广告优化
- 客服处理
- 数据分析
- 运营决策

核心理念：

```
输入业务目标
      ↓
AI Agent 分析
      ↓
调用 MCP 工具
      ↓
执行运营任务
      ↓
输出可审核结果
```

AI 负责分析、生成和执行；关键商业决策保留人工审核。

- 分析新品增长

- 分析价格区间

```

历史销售数据

市场报告
```

### 输出

```

```

# 四、设计原则

## 1. Agent独立运行

每个Agent负责一个专业岗位。

```
选品Agent ≠ 开品Agent ≠ Listing Agent
```

避免一个AI承担所有任务。

---

## 2. 输入输出标准化

每个模块都有明确接口：

```
Input
 ↓
Processing
 ↓
Output
```

方便扩展新的AI能力。

---

## 3. 本地优先架构

运营人员电脑运行：

```
Codex
 ↓
Skill
 ↓
Local MCP
 ↓
Chrome环境
 ↓
Amazon工具
```

不依赖单台中央电脑。
