# Amazon Creative Designer Skill

## 定位

Amazon Creative Designer 是晨玙科技 Amazon AI OS 第一阶段的 AI 美工 Skill。

目标：先让美工可以直接在 GPT/Codex 中使用 AI 完成 Amazon 商品视觉工作，而不是先开发复杂系统。

该 Skill 将已有的商品图生成能力和图片精修能力整合为一个统一入口。

---

# 使用方式

美工只需要描述任务并上传资料。

例如：

```
帮我制作这个产品的Amazon美国站7张图片。

产品资料：xxx
产品图片：xxx
竞品参考：xxx
卖点：静音、耐用、大容量
```

Skill 自动完成：

```
产品理解
 ↓
视觉方案规划
 ↓
图片生成
 ↓
图片优化
 ↓
输出商品图片
```

---

# 输入 Input

## 产品资料

```
产品名称
产品类别
目标市场
目标客户
产品规格
核心卖点
差异化信息
```

## 图片资料

```
产品原图
竞品图片
参考图片
历史素材
```

## 作图需求

```
图片数量
图片类型
视觉风格
特殊要求
```

例如：

```
7张Amazon Listing图片
美国站
高端科技风
突出静音功能
```

---

# 核心能力

## 1. 图片策略规划

分析：

- 用户购买逻辑
- 产品卖点
- 竞品视觉结构
- Amazon图片规范

输出：

```
Image Brief

第1张：主图
第2张：核心卖点
第3张：功能说明
第4张：使用场景
...
```

---

## 2. 商品图片生成

根据图片规划生成：

```
主图
功能图
场景图
尺寸图
对比图
```

---

## 3. 图片精修

用于已有图片优化。

原则：

- 保留产品真实性
- 不改变结构
- 最小修改

例如：

```
去除AI痕迹
修复边缘
调整背景
优化细节
```

---

# 输出 Output

## 图片方案

```
image_brief.md
```

包含：

- 图片目的
- 图片结构
- 卖点表达
- 制作要求
